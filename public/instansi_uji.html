Uji Lapangan Karhutla

Uji lapangan: apakah platform ini benar?

Platform menyebut cluster tertentu sebagai api prioritas, memperkirakan luasnya, dan menyatakan api sudah padam. Halaman ini memuat cara regu mengujinya di lapangan dan hasil yang masuk. Ambang lolos ditulis sebelum data masuk dan tidak diubah sesudahnya.

A. Protokol

Tujuan

Menjawab lima pertanyaan dengan data lapangan, bukan klaim: (Q1) seberapa sering cluster yang ditandai benar-benar terbakar, (Q2) seberapa sering api yang ditemukan regu luput dari satelit, (Q3) apakah peluang "akan membesar" bisa dipercaya, (Q4) seberapa dekat perkiraan luas dengan luas terukur, dan (Q5) apakah status "padam terverifikasi" benar-benar padam.

Siapa

Regu dan wakil instansi dengan akun Ruang Instansi (/instansi) yang mendapat tugas di wilayahnya. Regu berkode di /lapangan melaporkan api yang ditemukan; laporan itu dipakai menilai api terlewat (Q2). Tidak ada tugas khusus: isian yang sama dengan pekerjaan biasa, ditambah beberapa medan.

Kapan
  • Kunjungan pertama: paling lambat 24 jam sejak tugas muncul. Isi Konfirmasi di lokasi.
  • Ulang: H+1, H+3, dan H+7 sesudah dilaporkan padam, terutama di lahan gambut (kabar tindakan atau cek ulang dengan foto kedua).
  • Kabar lanjutan paling sedikit 72 jam sesudah kunjungan pertama bila api masih ada, dengan luas terbaru (untuk Q3).
  • Sampel uji: tiap minggu, tiap provinsi, sampai 5 cluster dipilih acak dari yang berstatus rendah atau firespot "mungkin" dan dekat akses. Kartunya berlabel Sampel uji (bukan api prioritas). Datang dan catat apa adanya; "bukan api" sama berharganya dengan "api ada".
Apa yang dicatat
  • Hasil: api ada, bukan api, atau sudah padam; lokasi GPS dan foto (foto wajib berGPS dan diambil paling lama 6 jam sebelum dikirim); luas terbakar dan luas yang sudah dipadamkan; kedalaman bara dan jenis lahan gambut atau mineral.
  • Tutupan lahan: gambut, semak/belukar, kebun sawit, HTI/akasia, hutan, pertanian, lain.
  • Cara mengukur luas (wajib bila luas diisi): keliling GPS, jalan keliling, taksiran mata, atau drone. Luas taksiran mata disimpan tetapi tidak dihitung dalam uji.
  • Opsional: jalur keliling GPS ringkas, arah api menjalar dan apakah tepinya masih aktif, tinggi nyala (di bawah 0,5 m / 0,5 sampai 1,5 m / di atas 1,5 m), angin di lokasi, dugaan penyebab, dan bekas terbakar baru (untuk hasil sudah padam).
  • Foto 4 arah dari titik yang sama: utara, timur, selatan, barat, sehingga tutupan dan luas dapat diperiksa ulang.
Cara mengukur luas
  1. Keliling GPS: berjalan di tepi area, ketuk Tandai titik di tiap sudut (paling sedikit 3), lalu pilih metode ini. Paling dianjurkan.
  2. Jalan keliling: ukur keliling dengan langkah atau odometer motor, catat bentuk kasar (persegi, memanjang), hitung luasnya.
  3. Drone: luas dari peta orto atau hitungan aplikasi drone.
  4. Taksiran mata: hanya bila tiga cara di atas mustahil. Tetap diisi, tetapi tidak dihitung.

Satu hektare = 100 m x 100 m. Pilih satu metode saja per isian.

Keselamatan
  • Jangan mendekati api demi data. Jarak aman dari tepi api aktif; angin dapat berbalik dalam hitungan menit.
  • Bara gambut bisa membuat tanah berlubang di bawah permukaan: uji pijakan dengan tongkat, jangan berjalan sendirian di gambut yang berasap.
  • Kenakan masker dan pelindung; hentikan pengukuran bila asap tebal atau regu lain memerlukan jalur.
  • Kalau keselamatan terancam, batalkan pengukuran. Tidak ada data yang lebih berharga daripada keselamatan regu.

C. Catatan jujur

  • Tugas otomatis hanya untuk level 3 dan level 2 bersyarat, jadi dari tugas saja hanya cluster yang sudah dicurigai yang pernah dikunjungi. Karena itu ada sampel kontrol acak; angka Q1 ditimbang kebalikan peluang terpilihnya.
  • Kunjungan hanya mungkin di tempat yang terjangkau regu, jadi hasilnya berlaku untuk cluster dekat akses, bukan seluruh kawasan.
  • Luas taksiran mata tidak dihitung dalam Q4.

Kolom Vonis hanya menunjuk satu dari tiga keadaan: belum cukup data, lolos, atau gagal menurut ambang yang dibekukan. Q2 deskriptif: belum punya ambang lolos.
