    Halaman ini mendaftar workflow GitHub Actions, berkas keluaran data, serta uji dan perintah.

    #Berkas keluaran data

    • public/data/ (sekitar 200 entri): titik panas (hotspot*.json, titik24.json), meta.json, laporan.json, wilayah.json, kluster*.json, kumulatif.json, musim_harian.json, fwi.json, peringatan.json, kekeringan (kekeringan_*.json), DIBI (dibi_*.json), feed (feeds/), konsesi (konsesi2026/), riwayat sel (riwayat_sel/), arsip kluster harian (kluster_hari/, disimpan 8 hari), dan lainnya.
    • public/<modul>/data/: banjir, bnpb, cuaca, gempa, gunungapi, inti, kekeringan, longsor, pesisir, prediksi, siklus, udara.
    • Yang tidak terbit: daftar di public/.assetsignore (berkas uji, data perusahaan bernama, arsip progresi, data tanpa izin).

    #Uji dan perintah

    PerintahCakupan
    npm run uji:agenGerbang tests/agen/*.test.mjs dan tests/inti/*.test.mjs
    npm run uji:wargaUji Worker dan D1 (tests/warga/*.test.mjs, 224 berkas)
    npm run uji:wascripts/wa/uji_urai_laporan.py uji dan tests/wa/lapangan_tarik.test.mjs; seluruh node --test tests/wa/*.test.mjs untuk bot
    npm run uji:banjir, uji:prediksi, uji:udara, uji:siklus, uji:sippa, uji:kemitraan, uji:layar, uji:insiden, uji:hidromet, uji:sensor, uji:ai, uji:paritasUji per modul
    npm run ujiRangkaian penuh (agen, warga, sippa, banjir, udara, prediksi, wa, siklus, paritas)
    node scripts/agents/uji_ulang.mjs <berkas uji>Menjalankan ulang uji yang gagal sesaat (dipakai terbit.yml)
    npm run agents:build, agents:checkMembangun dan memeriksa definisi agent dan KATALOG.md dari roster
    npm run bencana:js, bencana:cekMembangun dan memeriksa src/bencana.generated.js dari public/bencana.json
    npm run tinjauServer tinjau lokal di port 8800
    npm run dorongPush main dengan antre satu pendorong
    node scripts/agents/ilmu.mjs <pemilik, baca, cek, catat, kasus, atau prompt>Ilmu dan jejak agent
    npm run token:ukurUkur pemakaian token konteks
