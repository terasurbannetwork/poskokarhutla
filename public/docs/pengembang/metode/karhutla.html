    Metode karhutla

    Status uji balik tiap metode pada modul ini. Arti status ada di ringkasan status.

    #01. Peta utama karhutla

    Model belum lulus uji balik Hipotesis

    Bagian ini memuat model yang belum lulus uji balik. Angkanya tampil berlabel hipotesis, dan bagian yang bersangkutan ditandai HIPOTESIS.

    MetodeStatusCatatan
    1. Titik panas yang dihitung (angka utama)Bukan modelDefinisi angka utama (lokasi unik), bukan model.
    2. Cluster atau kompleks apiCampuranAmbang tingkat 3 diuji balik 2019 dan 2023 (menangkap 90 sampai 95 persen api besar); skor urutan dan kartu alasan peringkat hipotesis.
    3. Luas terbakar, belum padam, dan padamHipotesisPerkiraan satelit terkalibrasi ke luas resmi; angka resmi tetap dari KLHK dan BNPB.
    4. Prioritas provinsi (ambang masuk dan keluar)CampuranAmbang kajian (7 hari, 50 dan 25) lulus uji tertahan; aturan di layar (3 hari, 60 dan 30) dipilih sesudah uji balik ulang tanpa vonis lulus tertulis.
    5. Insiden apiHipotesisLuas terkoreksi adalah perkiraan perencanaan.
    6. Perkembangan api per insiden (HIPOTESIS)HipotesisUji tahan A10 bervonis belum; kartu belum ada di layar.
    7. Bangunan dekat api per insidenBukan modelHitungan geometri atas Open Buildings; baru tiga provinsi tercakup, selebihnya belum tercakup.
    8. Desa Waspada (rancangan, belum dibangun)RancanganBelum ada kode; status uji belum diuji.
    9. Alat gambar wilayah (rancangan, belum dibangun)RancanganBelum ada kode; alat hitung geometri, uji balik tidak berlaku.
    10. Indeks risiko historis, musim, dan peluang api besarTidak dinyatakanPola masa lalu, bukan model fisika; vonis tidak ditulis.
    11. Model lain yang tampil di peta (HIPOTESIS)HipotesisRincian ada di dokumen 03.

    #02. Pipeline data karhutla dan sumber data

    MetodeStatusCatatan
    1. Sumber deteksi dan pengambilanBukan modelPengambilan data FIRMS.
    2. Definisi angka utama: lokasi unikBukan modelDijaga swa-uji titik_unik.py.
    3. Sumber panas tetap dan gunung apiTidak dinyatakan
    4. Berhentinya S-NPP dan rasio NOAA-20 per S-NPPBukan modelRasio terukur, bukan model.
    5. Kompleks api (ST-DBSCAN)Bukan modelAda uji sensitivitas terdokumentasi; bukan uji balik.
    6. Keparahan, status taktis, dan prioritas pemadamanCampuranAmbang px24 dan FWI menangkap 90 sampai 95 persen api besar; uraian skor hipotesis.
    7. Klasifikasi firespotTidak dinyatakanHasil uji balik 2019 dan 2023 dilaporkan (api besar tidak pernah tertinggal tanpa status ya); kriteria lulus eksplisit tidak ditulis.
    8. Indeks cuaca kebakaran (FWI)LulusSwa-uji terhadap paket cffdrs dan fixture 1.730 baris.
    9. Insiden apiHipotesisFaktor per provinsi dari median luas resmi.
    10. Luas terbakar harian, belum padam, dan padamHipotesisPerkiraan satelit; angka resmi tetap dari KLHK.
    11. Luas terbakar dari citra Sentinel-2 (dNBR)HipotesisIndikatif; ambang RBR belum disetel.
    12. Gambut: estimasi bara, KHG, kelembapan tanahHipotesisEstimasi, belum divalidasi lapangan.
    13. KonsesiBukan modelIrisan geometri.
    14. Aturan Prioritas provinsi (kajian ambang hotspot)CampuranAmbang kajian lulus uji tertahan kejadian besar; aturan yang dipakai layar berbeda; ambang situasional hanya di teks panel.
    15. Lab InSAR gambut (rancangan)RancanganBelum ada kode; belum diuji.
    16. Kesegaran dan keterbatasan satelitBukan model
    17. Mesin pendukung lain di scripts/dataHipotesisHipotesis kecuali docstring menyatakan lulus.

    Model "akan membesar" dan tanda WASPADA (lolos.py)CampuranUji balik baik (AUC 0,91); uji prospektif belum_cukup_data.
