    #Rute API

    Seluruh rute /api/lapor/* didaftarkan di src/lapor_ai.js:1200 dan dibungkus penjaga yang menolak (503) bila rahasia sesi server belum terpasang. Header x-pb: 1 wajib pada permintaan tulis dari web.

    Metode dan jalurHakFungsi
    POST /api/lapor/pesanpelapor (nomor ketikan terikat perangkat, sesi /masuk, atau kunci mesin WA)Satu putaran percakapan
    POST /api/lapor/fotopelaporUnggah foto (JPEG, metadata dibuang)
    POST/PUT/GET /api/lapor/unggah/...pelaporUnggah video bersambung (mulai, bagian, selesai, status)
    GET /api/lapor/foto/:idtoken laporan atau stafBerkas foto atau video
    POST /api/lapor/susulanpelaporMulai Tambah kabar
    POST /api/lapor/darurat/cepatpelaporDarurat sekali ketuk
    GET /api/lapor/sesi, /cari, /sekitar, /kotakpelaporSesi aktif, cari wilayah, tempat sekitar, kabar untuk web
    GET /api/lapor/penting, /daerah, /raporpublikNomor penting, prakiraan daerah, rapor
    POST /api/lapor/nilaipelaporNilai 1 sampai 5 atas laporan
    POST /api/lapor/terjemah, GET /api/lapor/bahasapublik, batas lajuTerjemahan antarmuka, daftar bahasa
    GET /api/lapor/lacak, GET /api/lapor/unduh/:berkastoken lacakStatus dan dokumen laporan
    GET /api/lapor/alunpublik, cache 60 detikAlun-alun
    GET /api/lapor/hari-inipublik bila LAPOR_HARI_INI=1Kartu kejadian terverifikasi
    GET /api/lapor/bukti/:idtoken atau tanda publik per fotoFoto penanganan petugas
    GET /api/lapor/agregatakun kampus mitra, staf, adminData agregat (JSON atau CSV)
    GET/POST /api/lapor/izinkunci mesin, atau admin (POST)Daftar izin nomor dan peran
    GET /api/lapor/pdf/antre, POST /api/lapor/pdf/:xkunci mesinAntrean dan unggahan dokumen
    GET /api/lapor/kabar, POST /api/lapor/kabar/:xkunci mesinAntrean kabar WhatsApp (status, BPBD, tahap 2)
    GET /api/lapor/meja, GET /api/lapor/meja/:xstaf atau sesi profil BPBDDaftar, rekon, rincian, PIC, ruas jalan
    POST /api/lapor/meja/<nomor>/pichanya staf BNPB; 120 per jamMembuka nomor PIC BPBD utuh; tiap pembukaan tercatat di lapor_akses (src/lapor_ai.js:1015-1022, 1057)
    POST /api/lapor/meja/<nomor>/(balas, status, lihat, bukti, bukti-publik, teruskan, lepas, periksa, tindakan, ambil)staf atau sesi profil BPBD menurut bolehAksiAksi atas satu laporan
    GET /api/lapor/responsstaf BNPBWaktu respons per BPBD
    GET /api/lapor/peringatan/(cari, kunci, arah), POST .../(langganan, ubah, status, berhenti)publik, x-pb: 1, batas laju per IPPeringatan dini
    POST /api/lapor/data/(masuk, objek, batal, isian, nihil, tim, tutup, foto), GET .../(berkas, media)tim berkas (kuki lapor_data); isian hanya ketuaData lanjutan BPBD
    GET /api/lapor/data/daftar, POST .../tampil, POST .../terimastaf atau akun lembaga; tampil dan terima staf BNPBDaftar berkas, tampil data pribadi, terima penutupan

    Batas laju yang tertulis di kode: pesan 20 per menit, 60 per jam, 120 per hari per nomor; 300 per jam per IP (web); 120 per jam per perangkat; 5 laporan terkirim per hari; nomor ketikan 240 per jam per IP; ikatan perangkat baru 20 per jam per IP; Alun-alun dan halaman hari ini 120 per jam per IP; meja 600 baca per jam per profil; langganan peringatan 10 per jam per IP.
