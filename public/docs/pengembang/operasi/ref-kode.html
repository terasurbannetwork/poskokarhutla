    #Rute API

    Hak baca "peta" berarti: akun gerbang atau moderator, staf udara, pusdalops, koordalops, pimpinan, tmc, atau pemirsa Pusdalops. Semua rute /api/operasi/* yang membaca tabel op_* menjawab 503 sopan bila migrasi 0103 belum diterapkan.

    Metode dan jalurHakIsi
    GET /api/operasi/peta?tanggal=petabase, armada dengan status hari itu, gerak, temuan, renlap dan target (src/operasi_udara.js:20)
    GET /api/operasi/nilai?dari=&sampai=petametrik M1 sampai M11, maksimal 31 hari (:178)
    GET /api/operasi/monitor?dari=&sampai=petaaksi, hasil, foto, KPI per base dan armada, maksimal 31 hari (:221)
    GET /api/operasi/jejak?tanggal=petajejak ADS-B armada Centurisk97 dari adsb_posisi (maksimal 2.000 baris; aktif:false bila tabel belum ada) (:252)
    GET /api/operasi/foto/:idpetafoto dari R2 (private, no-store, nosniff, sandbox)
    GET /api/operasi/temuan?dari=&sampai=Bearer WA_MESIN (mesin)temuan dan gerak maksimal 7 hari untuk mesin renlap (:126)
    POST /api/operasi/renlapBearer WA_MESIN (mesin)simpan renlap draf per base; maksimal 20 base, 20 target per base, 256 KB per base; renlap berstatus dikirim tidak ditimpa (409) (:138)
    POST /api/operasi/dummySuper Adminmengisi atau menghapus data dummy (hanya untuk uji)
    POST /api/operasi/isian/gelar, /sortie, /hasil, /temuan, /hapusstaf pusdalops atau moderatorisian manual; tanggal hari ini sampai 7 hari ke belakang; maksimal 60 tulis per 10 menit per pengisi (src/operasi_isian.js:206)
    GET /api/operasi/isian/riwayat?tabel=&kunci= atau ?tanggal=petariwayat isian maksimal 200 baris
    GET /api/operasi/semai/berkas/:namapetaberkas prakiraan semai di R2 operasi/semai/
    GET /api/operasi/semai/target?tanggal=petatarget renlap OMC
    POST /api/operasi/semai/target, /target/hapusstaf pusdalops atau tmc, atau moderatorcatat atau hapus target (src/operasi_semai.js:85)
    GET /api/pb/titik?bencana=&prov=&kab=peta berwilayahdaftar sarana dan fasilitas
    POST /api/pb/titik, /titik/hapusmoderator, staf pusdalops (provinsinya), akun instansi pemda aktif (wilayahnya)isi, ubah, hapus lunak titik (src/pb_isian.js:433)
    GET /api/pb/titik/mesinHMAC RENLAP_KUNCItitik untuk mesin renlap; 20 kegagalan per IP per jam menjadi 429
    GET /api/pb/renlap, POST /api/pb/renlapbaca; tulis seperti titikdaftar (rentang maksimal 92 hari, src/pb_isian.js:298); minta renlap (maksimal 6 permintaan per jam per pengisi; tanggal hari ini sampai 7 hari ke belakang)
    POST /api/pb/renlap/selesaiHMAC (mesin)callback mesin: status draf atau gagal; tanda tangan mengikat isi berkas; selisih waktu paling lama 300 detik
    POST /api/pb/renlap/terbit, /selesai-tandaitulis seperti titikdraf menjadi terbit (berlaku 14 hari), terbit menjadi selesai; tidak ada jalan mundur
    GET /api/pb/renlap/berkas?id=&fmt=baca (pemirsa tidak)berkas json, kml, gpx, txt, pdf dari R2
    POST /api/pb/hasiltulis seperti titikhasil per target (1 sampai 100 butir) dan tindakan
    GET /api/pb/kepatuhan?bencana=&dari=&sampai=bacarekap, rentang maksimal 31 hari; per_tindakan bila migrasi 0153 ada
    GET /api/pb/tindakan?peringatan=, POST /api/pb/tindakanbaca: gerbang, pusdalops, koordalops, pimpinan, pemirsa, instansi wilayahnya; tulis seperti titiktangga tindakan
    POST /api/pb/dokumen/rakit, /bekukan, GET /api/pb/dokumen, /dokumen/berkasrakit: pusdalops, koordalops, moderator; bekukan: ditambah pimpinan; baca: staf dan gerbangdokumen (404 selama kemampuan.dokumen kosong) (src/pb_dokumen.js:180)
    GET /api/pb/ringkas, GET /api/pb/papan-skgerbang, staf, pemirsaringkasan dasbor per bencana, papan SK status darurat (src/pb_ringkas.js:86)
    /api/ops/* (tugas, garis api, sumber air, selang, periode, permintaan, drop, linimasa, patroli, drone, TMAT, bukti)akun instansi aktif pemegang cakupan tugas, moderator, atau staf berperan di wilayahnyaoperasi lapangan darat (src/operasi_lapangan.js:854); tugas di luar cakupan dijawab 404

    Peran baca khusus: untuk /api/pb/titik dan /api/pb/renlap, peran udara dan tmc hanya membaca karhutla dan udara (izinBaca, src/pb_isian.js:144).
