    scripts/udara/jalan.pyPenjalan berantai pipeline udara.

    scripts/omc/{bmkg_omc,panen,nilai,efek,verifikasi,banding_dalops}.pyJadwal resmi, arsip, evaluasi, analisis efek, verifikasi, pembanding.
    scripts/operasi/{semai_ifs,semai,semai_murni}.py, semai_bobot.json, fixture_semai.jsonMesin zona semai.

    public/operasi_semai.js, operasi_semai_murni.js, operasi_semai.css, renlap_omc.html, renlap_omc.js, renlap_omc.cssLayar semai dan renlap OMC.
    public/admin/omc.js, omc.cssHalaman admin sortie OMC.

    #Rute API

    Metode dan jalurHakIsi
    GET /api/cuaca/nowcastpublik, cache tepi 60 detikPeringatan nowcast aktif dari cuaca_nowcast dan terbit RSS (src/nowcast.js:155). 503 bila tabel belum ada.
    GET /api/cuaca/arsip?dari=&sampai=publik, cache 300 detikArsip ringkas CAP dari cuaca_arsip.
    GET /api/himawaripublik, cache tepi 300 detikHotspot Himawari dengan kolom baru, w, n_baru (src/worker.js:927, himawariRespons). Objek R2 hilang berarti kosong, bukan 500.
    GET /api/awan_tumbuhpublik, cache 300 detikAwan tumbuh cepat dari R2 data/awan_tumbuh.json (src/worker.js:930); 404 bila belum ada.
    GET /api/omc/sortie?sejak=publik, cache tepi 5 menitSortie nyata tanpa pengisi, catatan, dan baris dummy; bentuk tetap karena dibaca pipeline; paling lama 400 hari, maksimal 500 baris (src/omc.js:117-125).
    GET /api/omc/adminmoderator atau staf tmc, koordalops, pimpinan, operator_cc; pemirsa PusdalopsSortie dan operasi untuk halaman admin (src/omc.js:128, src/staf.js daftar izin pemirsa).
    POST /api/omc/sortie dan POST /api/omc/sortie/:idmoderator atau staf tmc; sesi staf wajib header x-pb: 1; batas 120 tulis per jam per akunBuat, ubah, hapus lunak sortie.
    POST /api/omc/operasisamaBuat operasi.
    POST /api/omc/dummySuper AdminIsi atau hapus data dummy OMC (aksi: isi atau hapus).
    GET /admin/omcmoderator atau staf berperanKerangka halaman admin.
    GET /api/operasi/semai/berkas/:namamoderator, staf udara, pusdalops, koordalops, pimpinan, tmcBerkas R2 operasi/semai/ dengan nama sah semai.json, angin_asap.json, arsip/<10 angka>.json, awan_<langkah>.png, asap_<langkah>.png (langkah kelipatan 3 sampai 36); cache-control: private, max-age=600.
    GET /api/operasi/semai/target?tanggal=samaTarget renlap OMC satu hari, tanpa baris terhapus.
    POST /api/operasi/semai/targetmoderator atau staf pusdalops, tmcBadan {zona_id, putaran, base_id, tanggal, catatan?}. Koordinat, skor, jendela, alasan diambil dari arsip R2; 404 bila zona tidak ada; 400 bila jendela lewat, tanggal bukan hari ini atau besok WIB, atau base tidak dikenal; 409 bila target aktif sama sudah ada; 429 setelah 30 isian per hari per akun (src/operasi_semai.js:61-86).
    POST /api/operasi/semai/target/hapussama{id, alasan} (alasan 5 sampai 300 huruf), hapus lunak, batas 30 per hari.
    GET /renlap-omchalaman statispublic/renlap_omc.html (src/worker.js:736); datanya lewat rute berkas di atas.

    Cron Worker (konstanta jadwal di src/worker.js:110; pemanggilan alarmHimawari di src/worker.js:1029, perbaruiNowcast di src/worker.js:1040, bersihkanAlarm di src/worker.js:1087): satu cron * * * * * (batas 5 jadwal akun gratis) memanggil alarmHimawari tiap menit, perbaruiNowcast tiap menit kelipatan 10, dan bersihkanAlarm pada rutinitas pembersihan.

    #Tabel D1 dan migrasi

    TabelMigrasiIsi
    cuaca_nowcast, cuaca_sumber0014_cuaca_nowcast.sqlCAP aktif dan stempel sumber.
    cuaca_arsip0021_arsip_cap_gunungapi.sqlArsip ringkas CAP permanen.
    alarm_himawari0043_insiden_waktu.sql (baris 9-23; migrasi yang sama menambah kolom tugas_api.terdeteksi_awal, himawari_awal, sumber_awal)Alarm api baru Himawari; kolom dikabarkan_pada, status, tugas_id.
    omc_operasi, omc_sortie0033_omc.sqlOperasi dan sortie OMC; hapus lunak; kolom dummy.
    op_semai_target0129_semai_target.sqlTarget renlap OMC dari zona; indeks unik (zona_id, base_id) untuk target aktif; indeks per akun untuk batas harian.

    Tabel yang dirancang paket semai tetapi belum ada di migrasi: log keputusan harian (op_semai_putusan) dan jejak sortie lanjutan.
