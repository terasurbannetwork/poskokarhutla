Mulai

Semua endpoint berada di bawah satu alamat dasar.

https://centurisk97.id/api/v1
  • Alamat dasar mengembalikan daftar semua endpoint dalam JSON (UTF-8).
  • Peramban dari situs mana pun boleh memanggilnya (CORS terbuka, tanpa cookie).
  • Hanya baca: GET dan HEAD.

Data mitra Perlu kunci

Kirim kunci di header X-API-Key; satu kunci hanya membuka cakupan yang diberikan padanya.

EndpointCakupanIsi
GET /api/v1/rumah-rusakrumah_rusakLaporan rumah rusak berat, sedang, ringan berstatus sah; maksimal 500 baris, terbaru dulu. Tanpa data pelapor, foto, dan catatan; koordinat dibulatkan 4 desimal (sekitar 11 meter). Parameter: bencana, prov (2 digit), kab, dari, sampai (YYYY-MM-DD), bbox (latMin,lonMin,latMaks,lonMaks)
GET /api/v1/rumah-rusak/rekaprumah_rusakJumlah berat, sedang, ringan per kecamatan (maksimal 1.000 baris, kec_dipotong: true bila lebih) dan per kabupaten/kota. Parameter: dari, sampai (maksimal 366 hari, bawaan hari ini WIB), bencana, prov
GET /api/v1/bangunan/terpaparbangunanBangunan Google Open Buildings yang terpapar, ringkasan nasional
GET /api/v1/bangunan/kecbangunanPaparan bangunan per kecamatan
GET /api/v1/bangunan/grid?prov=62bangunanPaparan bangunan per sel grid satu provinsi (prov wajib)
GET /api/v1/laporan-bnpblaporan_bnpbLaporan Harian dan Paparan Presiden BNPB. jenis=harian atau presiden (wajib). Tanpa tanggal: daftar tanggal tersimpan; dengan tanggal=YYYY-MM-DD: isi laporan hari itu
GET /api/v1/konsesi?prov=62konsesiPerusahaan pemegang konsesi satu provinsi beserta titik panas di dalamnya (prov wajib, 2 digit). Tambah nama= untuk menyaring satu PT (potongan nama, tanpa beda huruf besar-kecil) agar jawabannya kecil; tanpa prov keluar daftar provinsi yang tersedia. Data perusahaan hanya untuk mitra berkunci.
Kunci berbentuk pb_ diikuti 64 karakter. Kunci di alamat (query string) tidak dibaca supaya tidak tercatat di log. Simpan kunci di server Anda, jangan di JavaScript peramban; kalau bocor, minta admin mencabutnya.

Contoh kode

Ganti pb_GANTI_DENGAN_KUNCI_ANDA dengan kunci Anda.

Data publik, curl

curl "https://centurisk97.id/api/v1/data/meta"

Data publik, JavaScript

const r = await fetch("https://centurisk97.id/api/v1/data/meta");
if (!r.ok) throw new Error("galat " + r.status);
const meta = await r.json();
console.log(meta.jumlah_titik, meta.data_terakhir);

curl -H "X-API-Key: pb_GANTI_DENGAN_KUNCI_ANDA" \

const r = await fetch("https://centurisk97.id/api/v1/rumah-rusak?prov=62&dari=2026-10-01", {
  headers: {"X-API-Key": process.env.PANTAU_API_KEY},
});
const {jumlah, laporan} = await r.json();

Server MCP untuk asisten AI

Asisten AI yang mendukung Model Context Protocol bisa memakai data yang sama lewat satu alamat.

https://centurisk97.id/mcp

Memasang di klien MCP

Tambahkan server MCP jenis HTTP di pengaturan klien Anda. Tanpa kunci, hapus bagian headers; yang tersedia tool publik saja.

{
  "mcpServers": {
    "centurisk97": {
      "url": "https://centurisk97.id/mcp",
      "headers": {"X-API-Key": "pb_GANTI_DENGAN_KUNCI_ANDA"}
    }
  }
}

Tool berkunci hanya muncul bila klien mengirim header X-API-Key yang sah. Klien yang hanya menerima alamat server (tanpa pengaturan header) cuma mendapat tool publik, karena server ini belum memakai OAuth.

Transport Streamable HTTP tanpa sesi: tiap permintaan adalah POST JSON-RPC berdiri sendiri, GET dijawab 405. Panggilan dari halaman web di localhost atau jaringan privat ditolak (perlindungan DNS rebinding).

Kode galat

Galat berbentuk {"galat": "pesan"}.

KodeArtinya
400Parameter tidak sah (tanggal bukan YYYY-MM-DD, kode provinsi salah, dan sebagainya); pesannya menyebut yang salah
401Header X-API-Key tidak ada, kunci salah, atau kunci sudah dicabut
403Kunci sah, tetapi cakupannya tidak termasuk endpoint ini
404Rute atau nama data tidak ada, atau berkasnya belum tersedia
405Metode selain GET, HEAD, dan OPTIONS
429Batas laju terlewati; tunggu sebanyak header Retry-After (detik)
503Layanan belum tersedia; coba lagi nanti

Meminta kunci

Kunci diterbitkan admin untuk lembaga atau aplikasi tertentu dan bisa dicabut kapan saja.

Hubungi pengelola dan sebutkan nama lembaga, data yang dibutuhkan, dan keperluannya. Data publik tidak perlu kunci.
