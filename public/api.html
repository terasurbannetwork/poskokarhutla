Pantau Bencana

API data Pantau Bencana

Data yang tampil di situs bisa diambil langsung dari program Anda. Data publik terbuka tanpa kunci dan tanpa pendaftaran. Data yang di situs hanya terbuka bagi pengguna masuk (rumah rusak, bangunan terpapar, laporan harian BNPB) bisa dibaca mitra lewat kunci API yang diterbitkan admin. Semuanya hanya baca (GET dan HEAD).

Alamat dasar

https://pantau.terasurban.com/api/v1

Alamat itu mengembalikan daftar semua endpoint dalam JSON. Semua jawaban berformat JSON (UTF-8). Peramban dari situs mana pun boleh memanggilnya (CORS terbuka, tanpa cookie).

Bentuk alamatnya /api/v1/data/<nama>. Hanya nama di tabel ini yang dikenal; nama lain dijawab 404 beserta daftar nama yang sah. Memakai kunci

Kirim kunci di header X-API-Key. Kunci berbentuk pb_ diikuti 64 karakter. Kunci di alamat (query string) tidak dibaca, supaya tidak tercatat di log mana pun. Satu kunci hanya membuka cakupan yang diberikan padanya, dan hanya di /api/v1/*.

curl -H "X-API-Key: pb_GANTI_DENGAN_KUNCI_ANDA" \
  "https://pantau.terasurban.com/api/v1/rumah-rusak/rekap?dari=2026-10-01&sampai=2026-10-22&prov=62"

Contoh data publik

curl "https://pantau.terasurban.com/api/v1/data/meta"
const r = await fetch("https://pantau.terasurban.com/api/v1/data/meta");
if (!r.ok) throw new Error("galat " + r.status);
const meta = await r.json();
console.log(meta.jumlah_titik, meta.data_terakhir);

Contoh data berkunci dari server Anda

const r = await fetch("https://pantau.terasurban.com/api/v1/rumah-rusak?prov=62&dari=2026-10-01", {
  headers: {"X-API-Key": process.env.PANTAU_API_KEY},
});
const {jumlah, laporan} = await r.json();
Simpan kunci di sisi server. Kunci yang ditaruh di JavaScript peramban bisa dibaca siapa pun yang membuka halaman Anda. Kalau kunci bocor, minta admin mencabutnya.

Server MCP (untuk asisten AI)

Asisten AI yang mendukung Model Context Protocol bisa memakai data yang sama lewat satu alamat, tanpa menulis kode:

https://pantau.terasurban.com/mcp

Transportnya Streamable HTTP tanpa sesi: tiap permintaan adalah POST JSON-RPC berdiri sendiri, dan GET dijawab 405. Tool publik terbuka tanpa kunci. Tool berkunci hanya muncul di daftar bila Anda mengirim header X-API-Key yang sah dengan cakupan yang cocok. Batasnya 600 permintaan per jam per jaringan (tanpa kunci) atau 1.000 per jam per kunci.

Claude Code

claude mcp add --transport http pantau-bencana https://pantau.terasurban.com/mcp \
  --header "X-API-Key: pb_GANTI_DENGAN_KUNCI_ANDA"

Tanpa kunci, hapus baris --header; yang tersedia tool publik saja.

Cursor

Di ~/.cursor/mcp.json atau .cursor/mcp.json proyek:

{
  "mcpServers": {
    "pantau-bencana": {
      "url": "https://pantau.terasurban.com/mcp",
      "headers": {"X-API-Key": "pb_GANTI_DENGAN_KUNCI_ANDA"}
    }
  }
}
Connector kustom di claude.ai belum bisa mengirim header kunci (server ini belum memakai OAuth), jadi di sana hanya tool publik yang tersedia. Untuk tool berkunci, pakai Claude Code, Cursor, atau klien lain yang bisa mengatur header.

Panggilan dari halaman web di localhost atau jaringan privat ditolak (perlindungan DNS rebinding); klien desktop dan baris perintah tidak terpengaruh.

Kode galat

Galat berbentuk {"galat": "pesan"}.

KodeArtinya
400Parameter tidak sah (tanggal bukan YYYY-MM-DD, kode provinsi salah, dan sebagainya). Pesan menyebut yang salah
401Header X-API-Key tidak ada, kunci salah, atau kunci sudah dicabut
403Kunci sah, tetapi cakupannya tidak termasuk endpoint ini
404Rute atau nama data tidak ada, atau berkasnya belum tersedia
405Selain GET dan OPTIONS tidak diterima
429Batas laju terlewati. Tunggu sebanyak header Retry-After (detik)
503Layanan belum tersedia; coba lagi nanti

Batas laju

  • Data publik: tidak dihitung per kunci. Ambil seperlunya; berkas diperbarui paling cepat tiap 3 jam, jadi satu kali ambil per jam sudah cukup.
  • Data berkunci: 1.000 permintaan per jam per kunci.
  • Kunci salah: lebih dari 300 kali per jam dari satu jaringan membuat jaringan itu ditolak (429) selama sejam.

Sumber dan atribusi

Pantau Bencana mengolah data pihak lain. Bila Anda menampilkan ulang, sebut sumbernya:

  • Titik panas: NASA FIRMS (MODIS, VIIRS S-NPP, VIIRS NOAA-20).
  • Peringatan dini cuaca dan gelombang: BMKG (cantumkan sumber).
  • Kualitas udara: CAMS (Copernicus) lewat Open-Meteo; jumlah penduduk WorldPop. Angkanya prakiraan model, belum divalidasi dengan stasiun.
  • Indeks cuaca kebakaran (FWI): dihitung Pantau Bencana dari data cuaca.
  • Bangunan: Google Open Buildings.
  • Rumah rusak dan Laporan BNPB: diinput tim lapangan dan staf, bukan angka resmi BNPB kecuali disebut demikian.

Situs ini bukan kanal resmi BNPB, KLHK, atau BMKG. Untuk keputusan operasional, rujuk instansi yang berwenang.

Meminta kunci

Kunci diterbitkan admin untuk lembaga atau aplikasi tertentu, dan bisa dicabut kapan saja. Hubungi pengelola lewat formulir Kirim pesan di situs dan sebutkan nama lembaga, data yang dibutuhkan, dan keperluannya. Data publik di atas tidak perlu kunci.
