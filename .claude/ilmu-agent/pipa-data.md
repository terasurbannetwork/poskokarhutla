## Aturan & invarian

- Python 3.12 stdlib saja, tanpa `pip install` di Actions. Shapefile/TIFF/netCDF dibaca tangan (`penduduk.py baca_tiff`, `iklim.py`). Mesin ini `python3` = 3.14; generator laporan BNPB butuh 3.12 (`~/.local/share/uv/python/cpython-3.12-*/bin/python3`; f-string backslash gagal di 3.9). `python3 -I` tidak memuat user site: openpyxl butuh `site.addsitedir(site.getusersitepackages())`; skrip `-I` wajib berdiri sendiri (tak ada folder skrip di sys.path, mis. `tle.py`).
- Status kompleks (`aturan.py`): kelas FWI BMKG apa adanya (`kelas_fwi` <2, <7, <14, selebihnya). Keparahan S1-S3: S3 bila `px24 >= 10` atau (bertahan >= 4 hari dan `px24 >= 5`). Cuaca hanya MENAIKKAN status (S3 minimal level 2). Prioritas (level 3) = `px24 >= PRIOR_PX` (15) DAN FWI >= 7, atau FWI tak ada. "Tanggap darurat" tidak diberikan model. Level 3 selalu firespot H pada Hd/Hd-1 karena `2*AMBANG_MEDIUM_PX <= PRIOR_PX` (assert di `harian.py uji`). Gunung api (`aturan.GUNUNG_API`, radius 3 km) tidak jadi kompleks; titiknya tetap di `hotspot.json`.
- **Hitungan utama (keputusan pemilik 25 Okt 2026) = LOKASI UNIK ~375 m per hari WIB** (`titik_unik.py`) dari M, N, N20, N21, keyakinan sedang/tinggi (VIIRS n/h, MODIS >= 30), tanpa sel sumber panas tetap (`titik_palsu.json`, kecuali kawah); BUKAN titik mentah SiPongi. Kolom `hitung` di hotspot.json menandai yang dihitung; keyakinan rendah tetap digambar (jumlah titik memuatnya; luas/cluster tidak).
