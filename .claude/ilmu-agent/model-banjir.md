# Ilmu model-banjir

> Kelas: pengerja · Model: sonnet · Definisi: `.claude/agents/model-banjir.md`
> Dibaca SEBELUM kerja (`node scripts/agents/ilmu.mjs baca model-banjir`). Kasus baru
> ditambah SESUDAH kerja lewat `node scripts/agents/ilmu.mjs kasus model-banjir "..."`.

## Peta berkas & tabel

Semua di `scripts/banjir/` (kecuali uji). Wilayah lain banjir (hujan, sungai, rob, status, posko, peringatan, arsip_*, layar) milik `banjir`.

| Kelompok | Berkas |
| --- | --- |
| Model kab-hari | `model_kab.py` (dasar, ERA5 sampel 104 sel), `model_kab2*.py` + `nilai_kab2_ops.py` + `prediksi_kab2.py` (KAB2), `model_kab_hulu/tanah/debit/grrr.py`, `model_kab_campur.py` + `model_kab_campur_nilai.py` (CAMPUR, m=14), `model_dampak.py`, `model_bahaya.py` |
| Label | `label_bersatu*.py`, `label_banjir.py`, `label_kec.py`, `susun_label_v2.py`, `gfm_label.py` (label satelit GFM per kab-hari) |
| Fitur | `koreksi_bias.py`, `jam_era5.py`, `sm_era5.py`, `q2_pusat.py`, `kedap_kab.py`, `ambang_persentil.*`, `siaga_persentil.*` |
| Uji & prospektif | `uji_balik.py`, `uji_logbook*.py`, `prospektif.py` |
| Dokumen | `PRAREG-*.md` (pra-registrasi, termasuk `PRAREG-CAMPUR-AMANDEMEN.md` A-1..A-13), `RISET-MODEL-KAB.md`, `AUDIT-MODEL-2026-11.md` |
| Uji node | `tests/banjir/model_kab_campur.test.mjs` (swauji `uji` tanpa jaringan, dan `latih` nyata harus ditolak rapi) |

Pendamping `.sidik` (jejak sha), `.mulai` (O_EXCL), `.buka` (daftar uji yang sudah dibuka) ada di sebelah skripnya.

## Aturan & invarian

- Pra-registrasi dulu, baru latih: aturan, ambang, dan fitur dibekukan dalam `PRAREG-*.md` sebelum skor uji dilihat; jejak `.sidik` harus ada di HEAD, `.mulai` dibuat O_EXCL, label beku (sha dikunci).
- Label dipotong 2026-10-18. Data 2024-2026 (sampai 18 Okt) SUDAH TERBAKAR (daftar buka): jangan dipakai sebagai uji murni; ukuran CAMPUR memakai m=14 (selang 99,66%).
- Perubahan aturan sesudah uji dibuka = amandemen tertulis (`PRAREG-CAMPUR-AMANDEMEN.md`, A-1..A-13), arsip penanda, dan kunci sha label baru; tidak pernah diam-diam.
- Uji bocor: pemilihan sampel dan fitur statis memakai tahun latih sebelumnya saja (ekspansif), bukan leave-one-year-out.
- Python stdlib; pustaka berat (numpy, rasterio, pyarrow) hanya venv lokal untuk riset, bukan Actions.
- Skor yang tidak meyakinkan dilaporkan apa adanya; jangan mengubah split, ambang, atau seleksi demi lolos. Pemeriksa: `validasi-model`.

## Ranjau yang pernah meledak

- `data/raw/` tidak dilacak git dan hilang bersama worktree: pulihkan dari cadangan beku di R2 (`python3 scripts/umum/cadangan_beku.py pulih`; manifest `data/beku/manifest.json`; perintah daftar/unggah/pulih/cek) sebelum menarik ulang puluhan ribu panggilan.
- Open-Meteo menggantung/429 bila lebih dari 2 proses jalan bersamaan dan kuota jam 5.000 bobot mudah jebol; satu proses, jeda, mundur eksponensial.
- Kunci label berbentuk `pp|Nama`: ejaan kab beda antar sumber diam-diam tidak bertemu (lihat Kasus).
- Berkas "* 2.*" salinan iCloud: abaikan.

## Gerbang yang menghakimi

- `python3 scripts/banjir/<skrip>.py uji` untuk tiap model/label; `node --test tests/banjir/model_kab_campur.test.mjs`.
- `validasi-model` memeriksa pra-registrasi, kebocoran, dan klaim skill sebelum angka tayang.
- `npm run uji:agen` untuk kepemilikan berkas.
