# Logo

Logo BNPB dari `ppt-konsultan/mesin/merek/bnpb`, PNG 250×315 px (lambang 250×245 px).

- `bnpb-logo.png`: logo berwarna di latar putih. Slide isi: kanan atas, 27,4×34,6 pt.
- `bnpb-logo-transparan.png`: logo berwarna tanpa latar, untuk tint dan foto terang.
- `bnpb-logo-putih.png`: logo putih untuk panel navy dan foto gelap. Di panel gelap, logo boleh di lingkaran putih.
- `bnpb-lambang.png`: lambang saja.
- Bukan vektor resmi; ganti bila berkas resmi tersedia. Jangan diubah warnanya atau ditimpa hiasan.
