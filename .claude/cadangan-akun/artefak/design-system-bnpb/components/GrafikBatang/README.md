# GrafikBatang

Grafik batang harian gaya laporan harian BNPB: nilai di atas batang, tanggal dan persen perubahan di bawah.

- Nilai 7,6 pt tebal di atas, tanggal 6,5 pt `teks-3` dan persen 6 pt tebal di bawah.
- Batang pertama `pembanding` (abu), tiga terakhir pekat, sisanya oranye muda.
- Naik `oranye`, turun `biru`. Arah memakai ikon segitiga vektor atau kata naik/turun, tidak hanya warna. (Di web Centurisk97 arahnya beda: naik merah, turun hijau.)
- Tanpa label "data satelit" di grafik; sumber ditulis di baris Sumber slide.
