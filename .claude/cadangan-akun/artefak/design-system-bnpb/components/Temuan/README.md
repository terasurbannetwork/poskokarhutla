# Temuan

Daftar temuan dua kolom: tesis di atas, lalu butir berikon lingkaran navy dengan judul dan isi berangka.

- Tesis 12 pt tebal `navy`, paling banyak 2 baris. Butir: lingkaran navy 26 pt dengan ikon putih, judul 10,5 pt tebal `navy`, isi 10,5 pt `teks` paling banyak 3 baris, rata kiri-kanan.
- Jarak kolom 24 pt, pemisah `tint-netral-pita`.
- Tiap temuan dibuktikan angka di slide yang sama. Tanpa kode "Temuan A.1" atau "Finding" di judul (pemilik, 26 Okt).
