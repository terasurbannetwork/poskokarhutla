# TigaFase

Tiga kolom Prabencana, Tanggap darurat, Pascabencana berisi aksi bernomor dengan pil waktu.

- Kepala kolom navy, label kapital putih. Kode aksi kotak navy 20×13 pt, teks aksi 9 pt, pil waktu `tint-netral-pita`.
- Paling banyak sekitar 110 pt aksi per kolom; pemisah `tint-netral-pita`.
- Jenis aksi tertutup: Regulasi, Data, Infrastruktur, Kapasitas, Pembiayaan.
