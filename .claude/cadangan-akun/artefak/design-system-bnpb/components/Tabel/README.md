# Tabel

Tabel peringkat deck: kepala navy, baris Grand total di bawah kepala, nomor peringkat dalam lingkaran navy.

- Kepala `navy`, teks putih kapital 6,5 pt, SEMUA kepala rata tengah dan teks polos (tidak berbentuk pil). Kepala dua tingkat boleh.
- Isi 7,5 pt `teks-2`; angka rata kanan, tebal, `teks`, format Indonesia; kolom teks rata kiri. Garis baris 0,5 pt `garis`.
- Baris total `navy` teks putih 8 pt. Pada tabel wilayah ia tepat di bawah kepala dan tidak ikut diurutkan.
- Tanpa pil Resmi atau Terverifikasi. Pil status hanya bila statusnya bermakna, merah hanya untuk bahaya.
