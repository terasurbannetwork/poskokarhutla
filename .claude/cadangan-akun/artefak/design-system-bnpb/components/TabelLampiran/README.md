# TabelLampiran

Tabel data rinci di lampiran: tanpa kepala navy, kepala teks `teks-3` dengan garis 1 pt, baris tipis.

- Baris 18–21,6 pt, paling banyak 24 baris per slide. Kepala 20 pt, 8 pt tebal `teks-3`, rata tengah.
- Isi 8 pt `teks`, angka rata kanan format Indonesia, garis baris 0,5 pt `garis`.
- Tabel isi slide utama memakai Tabel (kepala navy); tabel lampiran sengaja lebih tenang.
