# PitaBawah

Pita aksi selebar isi slide di bagian bawah: label kecil, lalu tiga butir berikon dengan judul dan isi, dipisah garis tegak.

- Lebar 874 pt, tinggi 61–71 pt (baku 64,8), radius 6 pt, padding 11,5 pt.
- Nada: aksi (`tint-api-muda`, label dan ikon `oranye`, pemisah `api-2`), hujan (`tint-basah-muda`, `kategori-basah`, `air-2`), data (`tint-netral-muda`, `navy`, `netral-1`).
- Judul butir 9 pt tebal, isi 7,2 pt `teks-2` rata kiri-kanan. Judul dan isi dipisah baris.
- Pita aksi tanpa rujukan BMKG.
