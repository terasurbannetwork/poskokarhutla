# Penutup

Halaman penutup terang: "Terima Kasih" navy besar di kiri, garis aksen oranye, nama lembaga, foto kejadian di kanan memudar ke putih.

- Latar `kertas`. Foto mulai x 497 sampai tepi kanan, memudar ke putih di kiri, sama seperti Sampul. Logo berwarna 79,2 pt di (43,2; 39,6).
- "Terima Kasih" 54 pt tebal `navy` di y 194,4. Garis 2 pt `oranye` selebar 374,4 pt di y 288. Lembaga 18 pt tebal `biru-lembaga`, baris laporan 13 pt `teks-2`.
- Hiasan hanya gugus kotak di tepi bawah sambungan foto (lihat ElemenGrafis).
- **Selalu terang** (pemilik, 31 Okt 2026: "Jadikan terang", meneguhkan "Semua terang" 26 Okt). Versi navy di mesin deck lama tidak dipakai lagi.
- Sampul dan penutup tetap ditentukan pemilik per deck: paparan Presiden dan laporan harian tanpa penutup.
