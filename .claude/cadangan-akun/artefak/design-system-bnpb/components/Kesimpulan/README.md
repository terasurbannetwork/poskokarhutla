# Kesimpulan

Empat kartu kesimpulan bernomor dengan label jenis aksi, lalu pita arahan oranye selebar isi.

- Grid 4 kolom (paling banyak 2 baris), kartu 147,6 pt, radius 5,8 pt, padding 13 pt. Lingkaran ikon 31,7 pt, nomor 14 pt `pembanding` di kanan atas.
- Label 6,8 pt kapital `oranye`, judul 12,5 pt tebal paling banyak 2 baris, isi 7,8 pt `teks-2` paling banyak 4 baris.
- Arahan: pita `oranye` 44 pt, lingkaran putih berikon oranye, label "ARAHAN" 7,5 pt, isi 10,5 pt tebal putih.
