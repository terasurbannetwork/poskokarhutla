# DaftarIsi

Halaman daftar isi dan pembatas bagian: panel sisi kiri dengan nomor bagian besar oranye, daftar bagian di kanan dengan pil halaman.

- Dua opsi lewat `panel_sisi`: Terang (panel `tint-netral-muda`, foto di dasar memudar ke atas, teks navy) dan Gelap (foto penuh panel, gradien navy menipis ke bawah, teks putih). Contoh render ada di grup aset Panel.
- Baris aktif: latar `tint-api-muda`, garis kiri oranye, nomor oranye, pil halaman navy. Baris lain redup `teks-3` dengan pil `tint-netral-pita`.
- Hiasan hanya di zona tetap: pojok kiri bawah panel dan sambungan panel. Satu jenis elemen per deck (lihat ElemenGrafis).
- Foto panel diambil dari foto sampul.
