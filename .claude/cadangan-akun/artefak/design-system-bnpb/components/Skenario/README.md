# Skenario

Tiga kolom skenario dengan nilai dampak dan kelas kemungkinan lima tahun.

- Kepala 36 pt bertint, baris label 7,5 pt `teks-2` dan nilai 8 pt tebal rata kanan.
- Kotak kemungkinan 30 pt. Kelas tertutup: "< 0,2%", "0,2–1%", "1–5%", "5–25%", "> 25%".
- Angka skenario adalah estimasi: beri PilKeyakinan "Estimasi model" bila belum diuji balik. Angka di contoh ini ilustrasi.
