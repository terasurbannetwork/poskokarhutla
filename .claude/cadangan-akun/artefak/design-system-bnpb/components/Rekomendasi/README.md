# Rekomendasi

Baris rekomendasi tiga kolom: nama rekomendasi berikon, rincian langkah, penanggung jawab dan horizon waktu.

- Kolom di rasio 0 / 0,33 / 0,74. Kepala 6,5 pt kapital `teks-3` dengan garis `garis-kuat`, rata tengah.
- Baris 46,8–72 pt, pemisah `tint-netral-pita`. Lingkaran navy 26 pt, judul 9 pt tebal, rincian 8 pt rata kiri-kanan.
- Pil waktu `tint-netral-pita`: "100 hari", "2026–2027", "2028–2030". Kelompok: Internal BNPB atau Lintas K/L.
- Tanpa kode "R1" di judul slide; kode oranye kecil hanya bila deck kajian memerlukannya.
