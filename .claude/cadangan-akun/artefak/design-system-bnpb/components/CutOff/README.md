# CutOff

Pil CUT OFF DATA navy di kanan atas slide, menyebut jam batas data harian.

- Navy, tinggi 16,6–18 pt, lebar 186–220 pt, di (696; 70). Label 7 pt tebal `batas` berspasi 1 pt, nilai 9 pt tebal putih.
- Hanya untuk data yang diperbarui harian. Laporan harian bencana cut off 12.00 WIB, laporan harian karhutla 15.00 WIB.
- Tidak dipakai di deck mitra asing dan deck yang datanya sudah pasti.
