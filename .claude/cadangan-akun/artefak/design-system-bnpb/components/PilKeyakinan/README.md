# PilKeyakinan

Pil bergaris yang menandai tingkat keyakinan angka dan status usulan.

- Keyakinan: "Estimasi model" bergaris `oranye` (tambahan "belum diuji balik" atau "uji balik gagal"), "Asumsi kebijakan" dan "Penilaian pakar" bergaris `teks-3`.
- Status usulan: "Usulan baru" isi `navy` teks putih, "Sudah ada, perlu dikembangkan" bergaris `navy`, "Sudah ada" bergaris `teks-3`.
- Tinggi 14,4 pt, huruf 6,4 pt tebal.
- Pil "Resmi" dan "Terverifikasi" TIDAK dipakai lagi (pemilik, 26 Okt). Padanan web-nya pil "Hipotesis" di Centurisk97.
