# Legenda

Legenda kotak 8 pt dengan label 7,5 pt, untuk peta dan grafik.

- Kotak 8 pt bergaris `garis`, jarak kotak ke label 4 pt, antar butir 12 pt.
- Tiap bulatan, warna, dan arsir yang tampil wajib punya butir legenda; yang tidak tampil tidak masuk legenda.
- Ambang kelas ditulis di labelnya. Wilayah tanpa data: `tanpa-data` dengan arsir, label "Belum terdata".
- Kelas IRBI memakai skala api kelas 1, 3, 5 dengan nama resmi Rendah, Sedang, Tinggi; merah tidak dipakai untuk kelas indeks.
