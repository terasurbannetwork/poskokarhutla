# HalamanContoh

Satu layar Insight karhutla yang menyusun semua komponen Centurisk97 seperti di centurisk97.id, untuk melihat sistemnya bekerja bersama.

- Urutan: Header (dengan BencanaMenu dan tombol tema), PhotoHero, panel kiri (Breadcrumb, Field cari, KpiTile, Pill, Field pilihan), InsightCard dengan Segmented, lalu Table, Select, Pagination, Tooltip, dan Toast.
- Bisa dicoba: ganti rentang 24 jam, 7 hari, 30 hari; arahkan kursor ke batang atau baris tabel untuk tooltip; pindah halaman tabel; tombol bulan untuk tema gelap; Salin tautan memunculkan toast.
- Angka di halaman ini contoh tampilan, bukan data sungguhan.
- Halaman contoh, bukan komponen: jangan disalin utuh, ambil komponennya masing-masing.
