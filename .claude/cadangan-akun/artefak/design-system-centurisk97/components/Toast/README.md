# Toast

Pesan singkat di kanan bawah untuk konfirmasi tindakan (tautan disalin, berkas diunduh).

- `.toast` + `.on`, `role="status"`. Latar `ink`, teks `paper` (terbalik di kedua tema), radius 12px, `shadow-lg`.
- Satu kalimat pendek, tanpa tanda seru. Hilang sendiri setelah beberapa detik.
- Kesalahan yang perlu tindakan tidak memakai toast; tampilkan di tempat kejadian.
