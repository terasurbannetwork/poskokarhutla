# Segmented

Deretan pilihan berbentuk pil untuk satu pilihan dari beberapa (rentang waktu, ukuran, lapisan).

- Kelas `.seg`, tombol di dalamnya memakai `aria-pressed`. Aktif: latar `brand`, teks `on-brand`.
- Di kartu dan panel, deretan pilihan dibuat penuh ujung ke ujung (`.seg.penuh`), dibagi rata, boleh berikon 14px.
- Label bahasa Indonesia. Pemisah teks tidak pernah titik tengah.
