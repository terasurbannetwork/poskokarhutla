# Field

Isian form dan kotak cari untuk panel simulasi, filter, dan form warga.

- `.fld`: label `.lbl` kapital di atas, kontrol tinggi 36px, radius `r-sm`, latar `surface`, tepi `line`.
- `.cari`: pil 36px dengan ikon kaca pembesar di kiri; hasil muncul di kartu di bawahnya.
- Satuan ditulis di label dalam kurung. Pilihan selalu punya "Lainnya" bila daftarnya tidak lengkap.
- Fokus memakai cincin `info` bawaan.
