# Select

Pemilih bergaya pil (PilihCantik, `.pc`) yang membungkus `<select>` asli dan membuka menu kartu.

- Tombol `.pc-btn` tinggi 34px, huruf `control`. Saat terbuka, tepi `brand2` dengan cincin 3px 18%.
- Menu `.pc-menu`: kartu radius 14px, `shadow-lg`; butir terpilih bergradasi navy dengan tanda centang.
- Varian ganda (`.pc-multi`) memakai kotak centang di kanan. Daftar panjang memakai kotak cari `.pc-cari` di atas.
- Pemakai menyediakan `<select>` asli; skrip `/inti/pilih.js` yang menggambar tombolnya.
