# Breadcrumb

Remah wilayah di panel peta: Indonesia, provinsi, kabupaten/kota, berupa pil yang bisa diklik.

- `.crumb` berisi tombol pil; butir terakhir (wilayah aktif) berlatar `brand`, teks `on-brand`.
- Klik butir sebelumnya naik tingkat; hover memberi tepi `brand2`.
- Pindah wilayah memperbarui pil segera, peta dan daftar yang berat ditunda.
