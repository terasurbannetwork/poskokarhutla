# Tooltip

Tooltip kartu (`#tip`) yang muncul saat hover di grafik, peta, dan baris tabel.

- Kepala bergradasi surface berisi nama wilayah (`display` 13px) dan induknya.
- Angka utama `number` (20px tabular) dengan satuan di sampingnya, lalu pasangan kunci-nilai rata kanan.
- Naik (memburuk) memakai `naik`, turun memakai `turun`.
- Wajib ada di tiap grafik dan figur; jangan menulis angka yang tidak ada di data.
