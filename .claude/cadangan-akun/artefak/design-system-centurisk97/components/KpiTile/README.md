# KpiTile

Ubin angka ringkas di panel samping peta: label navy di atas, angka besar, keterangan.

- `.kpis` grid dua kolom, `.kpi` radius 14px. Label `.lbl` berlatar `brand`, teks `on-brand`.
- Angka `display` 22px 800, tabular, format Indonesia.
- Hanya untuk panel peta. Kartu Insight tidak memakai kotak KPI: angkanya masuk ke judul.
- Angka titik panas, luas, dan belum padam hanya dari sistem sendiri.
