# Table

Tabel data dalam satu kotak berujung bulat, kepala navy, baris bisa diklik.

- Bungkus `.tw` (radius `r`, tepi `line`, `shadow`). Kepala `thead th`: latar `brand`, teks `on-brand`, huruf `label`, garis bawah 2px `accent`.
- SEMUA kepala tabel rata tengah dan teks polos, tanpa pil.
- Angka rata kanan, `tabular-nums`, format Indonesia (titik ribuan, koma desimal), satuan di kepala kolom.
- Baris genap diberi tint tipis; hover tint `brand2` 6%. Tautan nama memakai `brand2`.
- Tabel panjang memakai Pagination di bawahnya.
