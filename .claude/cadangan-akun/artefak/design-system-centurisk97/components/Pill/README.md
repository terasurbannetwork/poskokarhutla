# Pill

Label status kecil berbentuk pil dengan titik warna, untuk tingkat bahaya dan keterangan model.

- Warna dari variabel `--w`: kelas `f0`–`f3` untuk skala bahaya, `info` untuk keterangan (mis. "Hipotesis" pada angka yang belum lolos uji balik).
- Latar `--w` 16%, teks `--w` digelapkan 72% (terang) atau dicerahkan 70% (gelap) supaya kontras terjaga.
- Teks pil selalu kata Indonesia; warna bukan satu-satunya pembeda.
- Jangan dipakai sebagai kepala tabel (kepala tabel teks polos rata tengah).
