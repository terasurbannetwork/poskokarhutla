# PhotoHero

Pita foto pembuka halaman Insight: foto lapangan penuh, gradasi gelap di bawah, judul putih.

- `.ins-hero` radius `r`, tinggi minimal 260px, latar `brand` bila foto gagal dimuat.
- Gradasi navy 5% ke 85% supaya teks putih terbaca di foto apa pun.
- Kredit foto wajib di pojok kanan atas (`small`): penulis dan lisensi, dari `public/img/kredit.json`.
- Foto nyata dari lapangan atau citra satelit; bukan ilustrasi atau gambar buatan.
