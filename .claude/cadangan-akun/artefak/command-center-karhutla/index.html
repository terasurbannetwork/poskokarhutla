Command Center Karhutla

Operator command center bekerja dari peta utama. Saat alert api level 3 muncul di pojok kanan bawah, operator menelepon BPBD setempat lalu mencatat hasilnya langsung dari kartu alert. Setiap perubahan tercatat: siapa operatornya, kapan, dan berapa lama konfirmasinya.

Aktif di produksi sejak 2 November 2026 · centurisk97.id

Akun operator

  • Peran staf: Operator command center. Super Admin membuat satu akun per orang lewat menu staf, supaya log menunjukkan siapa yang mengubah status.
  • Operator masuk lewat form staf di /admin/pantau dan langsung diarahkan ke peta utama.
  • Cakupan wilayah nasional.

Alert yang ditindaklanjuti

Alert adalah tugas karhutla level 3 yang dibuat dalam 7 hari terakhir. Di peta utama, alert tampil sebagai kartu di pojok kanan bawah, satu per satu. Bagi operator, alert yang belum diputuskan muncul lagi setiap kali peta dibuka sampai statusnya Ada api atau Tidak ada api. Pengunjung biasa melihat tiap alert sekali saja.

Tidak ada bunyi saat halaman dibuka. Bunyi hanya untuk alert yang baru masuk ketika peta sedang terbuka, dan tidak diulang.

  • Status hanya berpindah sesuai tabel. Lompat langsung dari Baru ke Ada api ditolak.
  • Bila dua operator mengklik alert yang sama hampir bersamaan, hanya satu yang tercatat. Yang lain melihat siapa yang sudah memegangnya.
  • Tidak ada api hanya label hasil konfirmasi. Label ini tidak menutup tugas lapangan dan tidak mengubah data titik panas.

Di mana tindak lanjut bisa dilakukan

  • Peta utama (tempat kerja utama): kartu alert pojok kanan bawah memuat status, siapa yang memegang, dan tombol tindak lanjut.
  • Meja Pantau (/admin/pantau): kartu "Api belum dikonfirmasi lapangan" memuat bagian yang sama, plus tombol Riwayat.
  • Layar command center (/command-center): tab Antrean untuk melihat semua alert sekaligus, dan tab Log untuk rekap dan unduhan CSV. Kartu alert di peta punya tautan "Buka meja operator" ke halaman ini.

Tampilan layar

Screenshot dari preview lokal dengan data contoh, masuk sebagai operator. Nama dan lokasi di gambar bukan data nyata.

Log

  • Setiap perubahan tercatat: waktu persis, alert, operator, status dari dan ke, serta catatan.
  • Log dikunci di database: tidak bisa diubah atau dihapus, dan disimpan 2 tahun.
  • Tab Log menyaring per tanggal (WIB, 00.00–24.00) dan per operator.
  • Ringkasan per operator: jumlah aksi, jumlah keputusan, median lama respons (alert dibuat sampai dipegang) dan median lama konfirmasi (dipegang sampai diputuskan).
  • Log bisa diunduh sebagai CSV untuk laporan.

Privasi dan batasan

Operator tidak bisa membuka direktori akademisi, data korban, buku kontak penuh dan nomor pribadi, daftar dan wajah petugas lapangan, modul tulis Pusdalops (logbook, rollcall, laporan khusus, pemulihan, antrean medsos, peringatan berantai), dan SIPPA. Di log dan CSV, tindakan admin tampil sebagai "Moderator".

Memulai

  1. Super Admin membuat akun staf berperan Operator command center untuk tiap operator.
  2. Operator masuk lewat /admin/pantau dan mengganti sandi awal.
  3. Untuk layar besar di ruang command center, buka peta utama.
  4. Kolom Telepon kantor BPBD di buku kontak dilengkapi, hanya dengan nomor kantor.

Catatan terbuka

  • Nomor HP pribadi yang terisi di kolom Telepon kantor ikut tampil ke operator. Pastikan kolom itu hanya berisi nomor kantor.
  • Catatan tindak lanjut masih menerima nomor telepon dan surel. Operator sebaiknya tidak menulis data pribadi di catatan.
  • Saat pertama kali masuk dan mengganti sandi awal, operator mendarat di Meja Pantau sekali itu. Masuk berikutnya langsung ke peta utama.
