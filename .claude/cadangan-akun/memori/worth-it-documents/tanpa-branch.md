Pemilik tidak mau ada branch selain main ("Gw ga mau ada branch ya", 3 Okt 2026, saat melihat v2-fondasi di GitHub Desktop).

**Why:** branch tambahan membingungkan di GitHub Desktop (muncul "Publish branch", pilihan merge) dan pemilik bekerja sendiri.

**How to apply:** commit langsung di main, termasuk saat memakai skill superpowers yang menyarankan branch/worktree; jangan membuat branch atau worktree tanpa diminta. Push tetap menunggu izin pemilik.
