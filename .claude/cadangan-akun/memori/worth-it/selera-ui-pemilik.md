Selera UI pemilik (dari koreksi langsung, 11-12 Okt 2026):
- Pil/tab/menu aktif: navy terisi, teks putih (bukan cincin emas).
- Anti ruang kosong: panel kanan sejajar judul; tidak ada kolom kanan kosong panjang; konten panjang lebar penuh dengan grid 2-3 kolom ([[anti-ruang-kosong]]).
- Tiap kartu/seksi punya kepala: ikon + judul tebal; situs harus terasa "berwarna", bukan teks polos.
- Grup pil/segmen tidak rata kiri: lebar penuh, tiap pil sama lebar.
- Baris meta tidak boleh string abu bertitik: harga tebal + ikon, selisih label warna vonis berpanah, tanggal miring + ikon kalender.
- Jawaban/hasil harus "sudah dilayout": kartu kaya, bukan teks mentah.
- Kartu listing gaya portal (Pinhome): banner berwarna + carousel kartu, harga besar, KPR mulai/bln, spesifikasi, simpan, chat.
- Footer dengan ikon sosial (TikTok, IG, FB), chat support kanan bawah.
- PDF laporan minimalis ala Apple.

**Why:** pemilik menilai dari tampilan produksi dan mengoreksi berulang; pelanggaran ini yang paling sering dikeluhkan.
**How to apply:** jadikan daftar periksa audit UI akhir tiap gelombang; cek visual 1440 dan 375, terang dan gelap, sebelum bilang selesai.
