Owner rule (30 Oct 2026, "Ingat ya bahwa kita BNPB. Catat"): the Direktori Jaringan Kebencanaan is BNPB's own tool. BNPB is the user, and BPBD/BPBA sit under BNPB's coordination ("under yurisdiksi kita"), so neither is ever a "partner strategis" or shown as an external mitra. Stars go only to outside organisations (kampus, K/L lain, LSM, swasta, internasional).

**Why:** calling BNPB's own regional agencies "partners" reads wrong to BNPB leadership.

**How to apply:** scripts/akademisi/hubung.mjs `strategis()` excludes BNPB/BPBD/BPBA by name regex (test in tests/agen/hubung.test.mjs). Apply the same framing to any copy: "jaringan BNPB", not "mitra BNPB" for BPBD. Related: [[direktori-semua-terhubung]], [[ruang-bnpb]].

Same rule in decks (30 Oct 2026, "Kenapa ada minta ke BNPB juga. Kan kita BNPB. Catat"): a BNPB deck never lists BNPB (or Pusdatinkom/DIBI) as a party we request data from; BNPB's own fixes are internal work, not requests. Deck titles for owner: plain one-line description of the slide content, not long numeric conclusion titles that disparage our own system. Score panels must say in plain words what the score means and which module is weak (Lemah/Cukup/Baik).
