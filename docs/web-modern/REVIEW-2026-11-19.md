# Review web modern Centurisk97 (19 Nov 2026)

Alat: Modern Web Guidance 1.0.1 (Google Chrome, Edge, Firefox, MDN), `legacy-scan public --json`,
ditambah pemeriksaan grep untuk butir yang tidak dicakup pemindai. Pemindai hanya memeriksa sekitar
20% katalog (52 aturan deterministik dari 209 panduan), jadi laporan ini bukan audit penuh
aksesibilitas atau kinerja.

Cakupan: 96 halaman HTML dan 213 berkas JS/CSS di `public/` (tanpa `public/data`).

## Ringkasan

| Prioritas | Temuan | Jumlah | Vonis |

## Yang sudah baik

- Semua halaman punya `lang`; semua `<img>` punya `alt`; zoom tidak dikunci.
- `color-scheme` dipasang di token tema; `prefers-reduced-motion` dihormati di 62 berkas.
- `:focus-visible` dipakai di 91 berkas CSS; `loading="lazy"` di 42 berkas; header CSP ada di `_headers`.
- Satu-satunya halaman tanpa `viewport` adalah `og/template.html` (templat gambar bagikan, bukan halaman).

## Urutan pembenahan yang diusulkan

1. SRI untuk semua sumber CDN berversi. **Selesai 19 Nov 2026 untuk tag HTML**: 34 tag maplibre 4.7.1 di 17 halaman
   memakai hash sha512 resmi cdnjs (dicocokkan dengan bayt yang dilayani) + `crossorigin="anonymous"` +
   `referrerpolicy="no-referrer"`; pemindai 16 temuan jadi 0; peta `/gempa/` diuji termuat (maplibre 4.7.1, kanvas tampil).
   **Belum**: pemuat dinamis di JS (jspdf, jspdf-autotable, pptxgenjs, xlsx, xlsx-js-style, docx, html-to-image,
   satellite.js, maplibre-contour) yang menyuntik `<script>` saat diklik; pemindai tidak melihatnya.
2. Audit `innerHTML` yang menyisipkan data luar oleh `security-reviewer`, mulai dari layar publik.
3. Warna literal di blok dark lokal pindah ke token `light-dark()` saat berkasnya disentuh (sejalan dengan ratchet `gerbang-token-warna`).
4. Sisanya (array, groupBy, structuredClone, dialog) ikut saat berkas disentuh; tidak perlu commit khusus.

Data mentah pemindaian tidak di-commit (194 KB); ulangi dengan
`npx -y modern-web-guidance@latest legacy-scan public --json`.
