# Sekilas dan cara masuk

Halaman ini menjelaskan apa itu peta karhutla, cara masuk, istilah yang dipakai, dan menu tab di bagian atas.

Peta karhutla adalah halaman beranda Centurisk97 (centurisk97.id). Halaman ini menjawab tiga pertanyaan: di mana satelit melihat tanda api hari ini, api mana yang sebaiknya didahulukan, dan apakah cuaca mendukung api menjalar. Titik panas yang saling berdekatan digabung menjadi satu kompleks api (disebut cluster), diberi status, lalu diurutkan supaya petugas tidak perlu membaca ribuan koordinat mentah.

Semua angka di halaman ini berasal dari satelit, bukan dari pengamatan langsung di lapangan. Angka resmi tetap berasal dari laporan KLHK dan BNPB.

## Masuk ke halaman

Halaman utama (centurisk97.id) memerlukan masuk lebih dulu. Pilih pintu sesuai jenis akun Anda:

| Anda siapa | Masuk lewat |
| --- | --- |
| Staf (BNPB, Pusdalops, BPBD) | centurisk97.id/admin/masuk |
| Pengguna umum | centurisk97.id/masuk, memakai nomor WhatsApp dan kode sekali pakai |
| Petugas instansi (TNI, Polri, pemda) | centurisk97.id/instansi |

Tombol atau tab yang tidak terlihat di layar Anda berarti belum diberikan kepada akun Anda. Akun pemirsa hanya melihat tab yang diberikan kepadanya. Bila tidak bisa masuk, misalnya lupa kode atau akun belum ada, hubungi pengelola akun di unit Anda.

## Istilah yang dipakai di halaman ini

| Istilah | Artinya |
| --- | --- |
| Titik panas | Lokasi yang dideteksi satelit lebih panas dari sekitarnya. Ini tanda kemungkinan api, belum tentu api |
| Kotak (piksel) | Satu petak pengamatan satelit. Satelit tidak melihat titik, tetapi petak berukuran sekitar 375 m kali 375 m (sekitar 1 km pada satelit yang lebih tua) |
| Lintasan | Satu kali satelit melewati wilayah Anda. Satu satelit lewat sekitar dua kali sehari |
| Cluster (kompleks api) | Kelompok titik panas yang saling berdekatan, diperlakukan sebagai satu api. Panduan ini hanya memakai kata cluster |
| Insiden | Cluster berstatus 2 ke atas yang diberi nomor tetap supaya bisa diikuti dari hari ke hari |
| Indeks bahaya kebakaran (FWI) | Angka dari BMKG yang menunjukkan seberapa mudah api menyala dan menjalar karena cuaca. Makin tinggi makin berbahaya |
| Daya pancar panas (FRP) | Ukuran seberapa kuat panas yang dipancarkan api menurut satelit |
| Hipotesis | Model yang belum terbukti cukup tepat. Penjelasannya ada di halaman [Indeks risiko dan model lain](/docs/peta-karhutla/risiko-model) |

## Menu tab di bagian atas

Tab yang tampil di menu staf dan instansi: Peta, Dalops, Insight, Saham, Berita, Tren, Dampak, Metode, Simulasi, Monitor, dan Laporan. Tab Dashboard (untuk pimpinan), Posko, Informasi, Cluster, Satelit, Tentang, dan Foto disembunyikan dari menu supaya tidak ramai, begitu juga tab Operasi yang tersembunyi secara bawaan. Tab yang disembunyikan tetap bisa dibuka lewat tautan langsung. Di sisi kanan kepala halaman ada keterangan jam data satelit terakhir, tautan laporan harian, ikon Prioritas provinsi, pengganti tema terang atau gelap, dan tombol keluar.
