# Peluang api 7 hari dan lainnya

Halaman ini menjelaskan peluang api 7 hari ke depan, perhitungan pendukung lainnya, dan status uji tiap perhitungan.

## 14. Peluang api 7 hari ke depan

Layar memperlihatkan peluang sebuah wilayah melewati tingkat bahaya api dalam 7 hari. Caranya:

1. Prakiraan cuaca dijalankan dalam 51 skenario sedikit berbeda, sehingga kita tahu rentang kemungkinan, bukan satu tebakan.
2. Untuk tiap kotak 0,5 derajat dan tiap skenario, dihitung apakah FWI melewati 7 atau 14.
3. Peluang wilayah adalah rata-rata pecahan skenario yang melewati ambang di kotak-kotak wilayah itu. Contoh: jika dalam sebuah kotak 30 dari 51 skenario menunjukkan FWI di atas 7, peluangnya sekitar 59 persen.
4. Peluang diberi keterangan seberapa sering kelas bahaya itu memang berujung titik panas di data masa lalu.

Ini peluang wilayah, bukan peluang satu titik. Seberapa bisa dipercaya: HIPOTESIS. Pengukuran masa lalu memakai cuaca yang sebenarnya terjadi, bukan prakiraan sehari sebelumnya, dan contoh wilayahnya condong ke daerah rawan, sehingga hasilnya cenderung terlalu optimistis.

## 15. Perhitungan pendukung lainnya

- **Rencana pencegahan**: arahan perencanaan per kecamatan yang langganan api, berdasarkan riwayat bulan terbakar, gambut, konsesi, kanal, desa, jumlah penduduk, dan jarak ke posko. Ini arahan perencanaan, bukan perintah. Belum ada uji balik yang tercatat.
- **Rekomendasi cara pemadaman**: saran per kelompok api berdasarkan aturan. Aturan yang datanya tidak ada dilewati. Kedalaman bara hanya ditaksir kasar dari energi panas satelit, bukan ketebalan gambut.
- **Pola lokasi per kluster**: membandingkan titik 7 hari terakhir dengan rata-rata tahunan di sekitar 16 km, untuk melihat apakah lokasi itu memang langganan api.
- **Daerah senyap**: kabupaten atau kota yang punya tanda bahaya (titik panas 3 hari, atau status banjir dan longsor Siaga ke atas) tetapi tanpa laporan harian dari Pusdalops. "Tanpa laporan" hanya menurut laporan yang terbit dengan jeda 1 sampai 2 hari; laporan warga dan BPBD yang baru masuk belum terhitung.
- **Pembanding luas terbakar**: luas hitungan satelit kami dibandingkan dengan data MapBiomas Fire Indonesia. Bila datanya belum terbit atau tidak terjangkau, pembanding ditulis "belum tersedia", bukan nol.

Semua perhitungan di bagian ini diperlakukan sebagai hipotesis atau arahan perencanaan kecuali disebut lulus uji.
