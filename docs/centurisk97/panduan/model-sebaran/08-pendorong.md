# Pendorong api dan skor prioritas

Halaman ini menjelaskan faktor pendorong api, awal musim, tren, dan skor prioritas penempatan sumber daya.

## Pendorong api, awal musim, dan tren

Pendorong: sistem membandingkan peluang api membesar antar kelas suatu faktor, lalu memberi rasio terhadap kelas acuan. Contoh: api di gambut kira-kira 3,6 kali lebih mungkin membesar dibanding di tanah mineral. Konsesi yang pernah disanksi kira-kira 2,6 kali dibanding konsesi lain. Angin hanya sedikit menjelaskan arah pergeseran harian: 30 persen pergeseran jatuh dalam 45 derajat dari arah angin, padahal tebakan acak memberi 25 persen.

Awal musim kebakaran: musim dianggap mulai ketika jumlah titik panas mingguan naik jauh di atas biasanya (paling sedikit dua kali nilai tengah tahun-tahun dasar, dan tidak kurang dari 10 titik per 7 hari) dan bertahan 14 hari berturut-turut. Hasil ditulis berdampingan untuk dua rentang tahun dasar karena hasilnya peka terhadap pilihan itu.

Tren 25 tahun: titik panas MODIS menunjukkan penurunan nasional sekitar 7,8 persen per tahun, tetapi sebagian penurunan itu disebabkan bergesernya orbit satelit, bukan semata berkurangnya api.

## Skor prioritas penempatan sumber daya

Sistem juga menguji skor prioritas penempatan regu, yang menggabungkan peluang membesar dengan paparan. Skor diuji terhadap aturan operasi yang berlaku sekarang. Hasilnya belum cukup baik: satu versi kalah, versi lain unggul tetapi belum mencapai syarat. Akibatnya, skor ini tidak ditampilkan sebagai saran dan belum dipakai menentukan penempatan regu.
