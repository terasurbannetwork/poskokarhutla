# Tolok ukur internasional

Tanggal: 1 November 2026. Tiap baris: buktinya, batas bukti, dan pelajaran khusus untuk strategi desa langganan Indonesia.
Penanda: **[V]** angka ada di sumber yang dikutip, **[T]** belum terverifikasi atau hanya klaim pihak sendiri. Pencarian dilakukan sekali per topik; angka kunci perlu dicek ulang di sumber aslinya sebelum masuk deck resmi.

## 2. Pelajaran lintas program

| Pelajaran | Dasar | Yang kita lakukan |
| --------- | ----- | ----------------- |
| Rantai peringatan terakhir ke manusia adalah titik lemah | CPP | Pelapor desa, WA, pengingat H+1 dan H+3 |
| Pemicu dan dana disepakati sebelum musim | EAP IFRC, Pooling Fund | Naskah pemicu desa langganan ke Kemenkeu dan Kemenko PMK |
| Program yang bergantung satu lembaga akan berhenti | NOAH | Banyak pemilik, data terbuka, anggaran rutin |
| Laporan warga untuk kalibrasi | PetaBencana.id | Daerah senyap diperiksa dengan telepon dan jawabannya masuk logbook |
| Klaim vendor diuji tanpa vendor | Dryad, Meshtastic | Uji prospektif dengan pembanding sebelum membeli |
| Drone untuk barang kecil dan mendesak | Zipline | Uji skala kecil |
| Prakiraan global belum tentu cukup untuk sungai kecil tropis | Flood Hub | Ukur dulu pada data logbook |
| Prakiraan harian lemah, kepastian musim kuat | Logbook kita: ETS banjir 0,006 luar-sampel 2022; 85 kab banjir dan 52 kab longsor 7 dari 7 tahun | Aksi pra-musim di desa langganan, prakiraan untuk eskalasi |
