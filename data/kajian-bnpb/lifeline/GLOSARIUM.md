# GLOSARIUM: Status Lifeline

| Istilah | Arti |
| --- | --- |
| Lifeline (layanan dasar) | Layanan yang menentukan warga bisa bertahan dan pulih: listrik, sinyal, air bersih, jalan dan akses, BBM, faskes, pangan, pengungsian. |
| Sel | Satu kab x satu layanan dalam satu kejadian. |
| Status resmi | Warna yang ditetapkan staf, tampil di kisi. |
| Usulan | Warna yang dihitung mesin dari isyarat; saran, bukan status. |
| Isyarat | Satu masukan yang sudah ada di sistem (laporan warga, kendala logbook, unit rusak meja, kebutuhan titik pengungsian). |
| Bukti | Isyarat yang dipilih staf atau catatan staf yang menempel pada status resmi. |
| Hijau | Berfungsi. |
| Kuning | Terganggu sebagian. |
| Merah | Lumpuh. |
| Abu | Tidak diketahui; bawaan sampai ada bukti. |
| Basi | Status resmi tidak diperbarui lebih dari 24 jam. |
| CLSS | Community Lifeline Status System milik DHS S&T; rujukan aturan bukti. |
| IODA | Internet Outage Detection and Analysis (Georgia Tech); padam internet per provinsi. |
| Black Marble | Produk lampu malam NASA VIIRS untuk pemadaman listrik. |
