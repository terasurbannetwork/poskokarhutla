# KEPUTUSAN-KEMAMPUAN: prediksi, simulasi, peringatan dini, pemodelan, dan analisa dampak disilangkan ke semua bencana

Dokumen ini menang atas semua dokumen lain di folder ini. Keputusan pemilik dicatat apa adanya. Hal yang belum diputuskan ada di bagian Q dan tidak dijawab dengan karangan; bawaan sementaranya ditandai **[BAWAAN SEMENTARA]**.

## Masalah

Tiap bencana punya keunggulan sendiri di lima bidang inti, tetapi keunggulan itu tidak menyebar:

- **Karhutla:** model eskalasi titik api punya skill historis terbesar (Brier skill 0,364 lawan laju dasar), tetapi masih `boleh_tampil=false` karena selang belum ada dan vonis prospektif belum keluar. Model sel, mesin fisika, dan jejak api kalah dari persistensi. Karhutla juga punya gerbang tampil gagal-tertutup.
- **Banjir:** disiplin pra-registrasi bersidik dan pembanding produk luar terbanyak.
- **Gempa:** rantai dampak fisika sampai korban jiwa, model generik lawan disesuaikan yang dipilih dengan log-likelihood, dan uji kesetaraan Python-JS.
- **Gunung api:** front Pareto evakuasi, replay Merapi 2010, dan prospektif arah abu (82% lawan acak 25%, n kecil, belum dibanding klimatologi).
- **Kekeringan:** uji kualitas label, model bayangan, dan hindcast.
- **Udara:** MOS ke sensor yang lulus di arsip, serta atribusi sumber.

Inventaris 24 Nov 2026 (`riset/R1` sampai `riset/R4`, sekitar 330 teknik dengan berkas dan vonis) memetakan celahnya. Matriks silangnya ada di `RISET.md`.
