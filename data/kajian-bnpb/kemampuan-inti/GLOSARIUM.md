# GLOSARIUM: Kemampuan Inti

| Istilah | Arti |
| --- | --- |
| Persistensi | Prakiraan "besok sama dengan hari ini". Pembanding wajib. |
| Klimatologi kab x bulan | Laju kejadian per kab per bulan dari periode latih. Di bencana berlabel laporan, ia juga mencerminkan kebiasaan lapor. |
| Jumlah alarm sama | Membandingkan model dan pembanding pada jumlah peringatan yang sama, supaya POD dan FAR adil. |
| Sidik | Hash kode, kriteria, dan masukan yang mengunci sebuah uji sebelum hasilnya dilihat. |
| Buka sekali | Uji hanya boleh dinilai satu kali. Penanda O_EXCL menolak pembukaan kedua. |
| Gerbang tampil | Aturan yang menentukan apakah keluaran model boleh tampil sebagai angka: harus mengalahkan pembanding dengan batas bawah selang di atas nol. |
| Gagal-tertutup | Bila berkas gerbang hilang atau rusak, keluaran disembunyikan, bukan ditampilkan. |
| Model bayangan | Model calon yang dibekukan dan dinilai di samping model tayang tanpa ditampilkan sebagai prakiraan utama. |
| Selang konformal | Pita ketidakpastian yang cakupannya dijamin secara empiris dari residu kalibrasi. |
| Kurva kedalaman-kerusakan | Fungsi persen kerusakan bangunan menurut kedalaman genangan. |
| Lift | Berapa kali lebih mungkin kejadian B sesudah kejadian A dibandingkan laju biasanya. |
| Daerah senyap | Wilayah dengan sinyal bahaya kuat tetapi tanpa laporan. Layak ditanyakan, bukan vonis. |
| Faktor sisi aman | Faktor waktu tiba yang sengaja konservatif untuk keputusan evakuasi, terpisah dari angka tampilan. |
| Tak teramati | Kab-bulan tanpa cakupan sumber label. Bukan negatif. |
| Hipotesis | Keluaran yang belum lolos uji. Tampil berpil dan tidak dikirim keluar. |
