# GLOSARIUM: Perkiraan kerusakan satelit

| Istilah | Arti |
| --- | --- |
| Perkiraan satelit | Jumlah bangunan terdampak (terendam atau terbakar) dari citra, berlabel `estimasi-model`; bukan cacah resmi. |
| Terdampak | Bangunan yang pusatnya jatuh di area air atau area terbakar; bukan tingkat kerusakan. |
| Vonis | Hasil uji balik per bahaya: menunggu uji, gagal, lulus terbatas, lulus. |
| Lulus terbatas | Lulus hanya pada unit kabupaten karena kebenaran tidak lebih rinci. |
| Plasebo | Adegan pra-kejadian yang diukur dengan cara sama; model harus mengalahkannya. |
| Tebakan naif | Pembanding sederhana tanpa citra (jumlah bangunan dikali intensitas atau kedekatan); model harus mengalahkannya. |
| Kriteria terkunci | Ambang lulus yang ditulis dan disidik sebelum hasil dilihat. |
| Sentinel-1 RTC | Citra radar Sentinel-1 yang dikoreksi medan, dari Planetary Computer. |
| Amplitudo | Kekuatan pantulan radar; berbeda dari koherensi. |
| Koherensi, SLC | Kemiripan fase dua citra radar kompleks; dasar peta kerusakan gempa yang lebih kuat, belum tersedia di Planetary Computer. |
| Open Buildings | Dataset jejak bangunan Google v3, ambang keyakinan 0,70, terkunci. |
| xBD-S12 | Dataset 10.315 pasang citra Sentinel dari 16 bencana untuk penilaian kerusakan. |
| Copernicus EMS | Layanan pemetaan darurat Uni Eropa; tolok ukur. |
| unit_asal | Kolom asal angka pada baris Jitupasna; nilai baru untuk baris yang diterima dari perkiraan satelit (Q7). |
| DIBI | Data Informasi Bencana Indonesia; kebenaran uji. |
