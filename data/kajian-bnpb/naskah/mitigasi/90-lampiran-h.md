# Katalog Program dan Kekuatan Bukti {#lamp:program}

Katalog ini memuat seluruh {{angka:program.kompendium.n}} program dalam kompendium kedua kajian beserta kekuatan buktinya [@pantaubencana-2026-program-terbukti]. Rubrik kompendium memberi kuat untuk deret sebelum-sesudah resmi atau studi yang ditinjau sejawat dengan pola konsisten, bukan untuk uji kausal, dan belum terbukti berarti bukti dampak tidak ditemukan (@sub:praktik). Belum terbukti tidak berarti program tidak bermanfaat.

**Kedua program berbukti kuat berasal dari luar negeri, dan tidak satu pun program dalam negeri berbukti kuat** (@tbl:h-program). Status usulan hanya diberikan kepada program dalam negeri dan mengikuti tiga kode KEPUTUSAN P7. Program luar negeri tidak diberi status usulan; kolom kajian menunjukkan kajian yang memakai program itu, dan uraian program untuk kajian mitigasi ada di Bab 2, Bab 6, Bab 10, dan Bab 11.
