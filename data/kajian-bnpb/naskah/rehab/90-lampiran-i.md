# Katalog Program menurut Posisi Bukti {#lamp:program}

Katalog ini mengelompokkan program pembanding di @tbl:rr-praktik dan sebelas program Grand Design di @tbl:rr-program menurut posisi bukti dalam rubrik paket program terbukti [@pantau-program-terbukti]. Rubrik itu mensyaratkan dokumen evaluasi independen atau tinjauan sejawat yang dibuka untuk tingkat sedang. Laporan pelaksana paling tinggi bernilai lemah, begitu pula laporan mitra penyandang dana (@sub:rr-praktik). Bukti lemah berarti dampak program belum dievaluasi independen, bukan program gagal.

**Tidak ada program RR air atau akses yang berbukti kuat, dan tingkat tertinggi adalah sedang** (@tbl:i-katalog). Program dalam negeri yang sudah berjalan tidak disebut usulan baru; program jembatan TNI AD dan Polri berposisi program berjalan yang wajib dievaluasi dampaknya.
