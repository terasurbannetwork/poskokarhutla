## Urutan dan ketergantungan

```
DC-00 -> DC-01 -> DC-05 (uji generator) -> DC-02 -> DC-04
              \-> DC-03 (setelah DC-01 menetapkan slug) -> DC-06
DC-07 dan DC-12 setelah 14 berkas sumber selesai; DC-08 setelah DC-01 dan DC-05; DC-09 setelah DC-02
Restruktur (K6, K7, K8): DC-13 -> DC-14 (per modul, paralel) dan DC-15 -> DC-16 dan DC-17 -> DC-18 -> DC-19; DC-17 butuh keluaran DC-15 (daftar halaman dari peta);
DC-07 dan DC-12 diulang atas halaman baru setelah DC-14
```

Tiket DC-00 harus selesai sebelum folder `public/docs` atau `scripts/docs` dibuat; gerbang paket modul menolak
folder baru tanpa bagian baca-dulu. DC-10 dan DC-06 menunggu jawaban pemilik atas Q4 dan Q5.
