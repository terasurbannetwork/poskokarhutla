# GLOSARIUM: Pembiayaan risiko

| Istilah | Arti |
| --- | --- |
| DSP | Dana Siap Pakai, dana tanggap darurat BNPB; permohonan dicatat di meja DSP. |
| PFB | Pooling Fund Bencana, dikelola BPDLH dengan dukungan Bank Dunia dan Global Shield (angka dan sumber di RISET 1, belum diverifikasi). |
| BPDLH | Badan Pengelola Dana Lingkungan Hidup, pengelola PFB. |
| Jitupasna | Pengkajian kebutuhan pascabencana; sumber nilai kerusakan dan kerugian resmi. |
| Kerusakan | Nilai aset fisik yang rusak (unit x harga satuan). |
| Kerugian | Arus ekonomi yang hilang selama pemulihan (arus rupiah x bulan). |
| Perkiraan awal | Rentang kerugian dari model terdaftar sebelum Jitupasna; hipotesis sampai lulus uji balik. |
| Pra-registrasi | Rumus dan ambang model dibekukan sebelum data uji dilihat. |
| Uji balik | Membandingkan rentang model dengan nilai resmi kejadian lalu. |
| Lapis dana | Satu sumber dana (realisasi DSP, saldo DSP, saldo PFB); tidak dijumlah lintas lapis. |
| Parametrik | Pembayaran yang dipicu indeks fisik terukur (mis. magnitudo atau curah hujan) menurut polis. |
| Pemicu | Batas indeks yang tertulis di polis; hanya dibaca sistem, tidak pernah dibuat. |
| Basi | Isian saldo lebih tua dari batas jadwal pembaruan. |
| Menunggu | Angka belum bisa dihitung karena data belum ada; berbeda dari nol. |
