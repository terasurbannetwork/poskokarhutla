# GLOSARIUM

| Istilah | Arti |
| --- | --- |
| GEL | Kode arsip gelombang: tinggi gelombang maksimum harian per kab pesisir (m) dan levelnya. |
| CEX | Kode arsip cuaca ekstrem: embusan angin maksimum harian per kab (km/jam) dan levelnya. |
| Embusan | Kecepatan angin sesaat tertinggi (gust) pada ketinggian 10 m, bukan angin rata-rata. |
| HTH | Hari tanpa hujan berturut-turut; hari hujan = curah >= 1 mm (BMKG). |
| Level | 0 Normal, 1 Waspada, 2 Siaga, 3 Awas; untuk sel tampilan juga dipakai sebagai kelas warna. |
| Perlu tindakan | Kumpulan aturan "jika ini maka ini" (`aturan.json`) yang terpicu untuk hari terpilih. |
| Teruji | Kolom yang rapornya mengalahkan persistensi dan klimatologi pada >= 30 pasangan prospektif. |
| Tenggang | Jarak hari sasaran dari hari terbit: +1 besok, +2 lusa, +3. |
| Hipotesis | Keluaran model yang belum lolos uji balik; tampil dengan label, tidak dipakai sebagai status. |
