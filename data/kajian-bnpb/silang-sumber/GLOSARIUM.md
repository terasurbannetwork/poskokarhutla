# GLOSARIUM: Silang Sumber

| Istilah | Arti di modul ini |
| --- | --- |
| Silang sumber | Memeriksa satu sumber lawan kejadian, atau satu sumber lawan sumber lain. |
| Resmi | Pernyataan lembaga berwenang (BMKG, PVMBG), ditampilkan apa adanya. |
| Deteksi Centurisk97 | Hasil turunan kita dari data; bukan peringatan sebelum lolos uji balik. |
| a, b, c, d | Tabel kontingensi: a menyala dan terjadi; b menyala tidak terjadi; c tidak menyala tetapi terjadi; d tidak menyala dan tidak terjadi. |
| n kejadian | a + c. Di bawah 30, tanpa persen. |
| POD | Peluang terdeteksi: a / (a + c). |
| FAR | Rasio alarm palsu: b / (a + b). |
| CSI | Indeks keberhasilan kritis: a / (a + b + c). |
| ETS | CSI yang dikoreksi hit kebetulan. |
| Tenggang | Selisih hari antara prakiraan dan hari target (H-1, H-2, dan seterusnya). |
| Beku | Prakiraan yang sudah tersimpan di arsip sebelum periode targetnya mulai. |
| Prospektif | Dinilai hanya dari prakiraan yang dibeku sebelum kejadian; tidak diisi mundur. |
| Telat lapor | DIBI memuat kejadian dengan keterlambatan, sehingga alarm palsu tampak terlalu banyak. |
| Perlu dicek | Dua sumber berbeda lewat ambang, atau statistik melewati ambang. Bukan vonis. |
| Zona (tsunami) | Wilayah peringatan BMKG, ditulis seperti "KOTA-BITUNG". |
| Sebagian | Zona yang hanya mencakup sebagian garis pantai kabupaten. |
| Mc | Magnitudo kelengkapan katalog; di bawah itu gempa tidak tercatat lengkap. |
| Baseline | Laju gempa pembanding; bisa historis atau relatif (sekitar lawan sekitar). |
| Kejutan | Peluang ekor Poisson yang sudah dikoreksi jumlah sasaran. |
| Beruntun | Laju gempa kecil di satu sasaran jauh di atas baseline. Bukan prediksi gempa. |
| Tangga | Modul Tangga Peringatan (`data/kajian-bnpb/tangga/`); beda modul dengan ini. |
