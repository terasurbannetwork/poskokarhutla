# GLOSARIUM: tindakan lapangan per bencana

| Istilah | Arti di paket ini |
| --- | --- |
| Tindakan | Satu jenis kerja lapangan yang dicatat di logbook Pusdalops (evakuasi, pembersihan material, dropping air, dan seterusnya), berkode slug di katalog registri. |
| Katalog tindakan | Kunci puncak `tindakan` di `public/bencana.json`: 23 kode dan labelnya. |
| Daftar tindakan bencana | `kemampuan.tindakan` satu entri registri: kode yang boleh dicatat untuk bencana itu, urut persen logbook. |
| Logbook Pusdalops | Laporan harian Pusat Pengendalian Operasi BNPB, arsip 2011-2026; satuan hitung kejadian (`id_kejadian`). |
| Kejadian berisi | Kejadian yang paling sedikit satu entrinya punya teks di kolom upaya, kondisi, atau peralatan. |
| Persen logbook | Kejadian berisi yang mencatat tindakan itu, dibagi semua kejadian berisi bencana itu. |
| Ambang masuk | 2 persen kejadian berisi (ALGORITMA 3). |
| Operasi generik | Operasi, sarana, renlap, hasil, dan kepatuhan lintas bencana dari paket Paritas Bencana (W1), di seksi Sarana dan fasilitas `/operasi`. |
| Target renlap | Satu lokasi bernomor di renlap terbit; hasil dan tindakan dicatat per target. |
| Kaji cepat | Pengkajian cepat dampak dan kebutuhan oleh TRC atau BPBD di lokasi kejadian. |
| OMC | Operasi modifikasi cuaca (dulu TMC); di banjir untuk mengalihkan hujan. |
| SAR | Pencarian dan pertolongan korban (search and rescue), oleh Basarnas, TNI, Polri, BPBD. |
