# Lampiran A. Glosarium

| Istilah | Arti |
| --- | --- |
| API | Pintu akses resmi yang disediakan platform supaya program lain dapat mengambil data secara teratur dan sesuai aturan platform |
| Buku Besar Kejadian | Daftar kejadian bencana bernomor di sistem Centurisk97 yang menjadi rujukan semua modul |
| Cek Kabar Luar | Modul sistem Centurisk97 yang memeriksa berita dan data alam untuk kejadian yang belum dilaporkan selesai |
| Cloudflare D1 | Basis data yang dipakai Worker sistem Centurisk97 untuk menyimpan data olahan |
| Cloudflare R2 | Penyimpanan berkas privat untuk kabar mentah |
| Cloudflare Worker | Program di server Cloudflare yang melayani dashboard dan menerima data dari pengolah |
| GDELT | Proyek terbuka yang memantau berita dunia dalam 65 bahasa dan memperbaruinya tiap 15 menit |
| Hoaks | Kabar bohong yang sengaja atau tidak sengaja disebarkan |
| *Hotspot* | Titik panas yang dideteksi satelit, dipakai sebagai petunjuk kebakaran hutan dan lahan |
| JSON terstruktur | Keluaran model bahasa yang selalu memuat kolom yang sama, sehingga dapat disimpan dan dihitung |
| Kabar ulang | Kabar yang hanya membagikan ulang kabar orang lain, bukan laporan dari lokasi |
| Laporan langsung | Kabar dari orang yang melihat atau mengalami kejadian, biasanya dengan foto atau video dari lokasi |
| Model bahasa | Program kecerdasan buatan yang membaca teks dan dapat diminta menggolongkan atau meringkasnya; di kajian ini Claude Haiku 5.5 dan Claude Sonnet 5.5 |
| Prompt cache | Penyimpanan sementara petunjuk tetap untuk model bahasa supaya bagian itu tidak ditagih penuh setiap kali |
| Real time | Bekerja hampir seketika; di kajian ini berarti jeda 5 sampai 30 menit dari kabar terbit sampai muncul di layar piket |
| RSS | Berkas daftar artikel terbaru yang disediakan portal berita untuk dibaca program secara otomatis |
| Sidik akun | Kode satu arah yang dibuat dari nama akun; dapat membedakan akun tanpa dapat dikembalikan menjadi nama akun |
| Sinyal kejadian | Kumpulan kabar dengan jenis bencana dan kabupaten yang sama dalam jendela 3 jam, yang perlu diperiksa piket |
| Tagar | Kata berawalan tanda pagar (#) yang dipakai di media sosial untuk menandai topik |
| Token | Satuan potongan teks yang dipakai model bahasa untuk menghitung panjang masukan, keluaran, dan biaya |
| Uji balik | Pengujian aturan pada data masa lalu untuk melihat seberapa sering aturan itu benar dan salah |
