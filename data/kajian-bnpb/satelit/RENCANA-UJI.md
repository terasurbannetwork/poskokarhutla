# RENCANA-UJI: Pemantauan satelit

Kriteria vonis tiap detektor dikunci (kriteria + sidik + jangkar commit) sebelum data uji dibaca; uji `prasyarat` menolak jalan bila sidik tidak cocok. Tiap uji `uji` adalah self-check stdlib berkasus sintetis, tanpa jaringan.

| Kode | Yang diuji | Perintah bukti | Kriteria terima |
| --- | --- | --- | --- |
| T1 | Status sumber WLF | `python3 -I scripts/data/himawari.py uji` | sambungan ditolak menulis `status_sumber: terputus` dan `sejak` = acuan sah terakhir, berkas data lama tidak ditimpa; FTPS dicoba sebelum FTP polos; tanpa sandi di log |
| T2 | Status sumber di Worker | `npm run uji:warga` (`tests/warga/himawari*.test.mjs`) | ambang ALUR 3 tepat di tiga batas; `/api/status` memuat `status_sumber`; umur di atas batas tidak pernah `hidup` |
| T3 | Kartu Satelit | `node --test tests/inti/satelit.test.mjs` | `terputus` menyembunyikan angka lama dan menulis "sumber terputus sejak"; tanpa vonis `lolos` pil hipotesis ada; gerbang hilang atau rusak = hipotesis (gagal-tertutup); tidak ada "aman", "padam", "bebas api", "cerah"; 0 hanya bila status `ok` dan `awan_persen` tersedia |
| T4 | Pemindai | `python3 -I scripts/umum/himawari_pindai.py uji` | kunci S3 tersusun benar; segmen sintetis terbaca lewat fungsi `awan_himawari` (bukan salinan); satu detektor galat tidak menghentikan yang lain; geometri matahari pada tiga kasus rujukan dalam 0,5 derajat |
| T5 | Ukur pemindai | `python3 scripts/umum/himawari_pindai.py ukur --pindai <YYYYMMDDHHMM>` | MB, detik unduh, detik hitung tercatat; total <= 4 menit di runner |
| T5b | Batas waktu | `python3 -I scripts/umum/himawari_pindai.py uji` (kasus batas waktu) dan satu run `satelit.yml` dengan unduhan diperlambat sengaja | run yang melewati 8 menit gagal merah, tidak menulis `selesai` atau potongan setengah jadi (tulis terbaru dan potongan hanya sesudah semua detektor selesai), lalu pindaian itu disusul oleh Worker |
| T6 | Pemicu Worker | `npm run uji:warga` (`tests/warga/satelit_picu.test.mjs`) | satu pindaian dipicu sekali; tanpa token lewat; host S3 tetap; daftar tanpa 6 kanal tidak memicu; galat dispatch tidak menandai pindaian dipicu |
| T6b | Susulan dan duplikat | `npm run uji:warga` (`tests/warga/satelit_picu.test.mjs`, kasus susulan) | objek S3 yang muncul menit ke-25 tetap dipicu; cron terlewat 60 menit menyusul 6 pindaian dalam 2 tik, terbaru dulu, <= 6 cek S3 dan <= 3 dispatch per tik; pindaian > 6 jam tidak dipicu dan dihitung `pindaian_hilang`; dipicu tanpa `selesai` sesudah 20 menit dipicu ulang paling banyak 2 kali lalu `gagal_tetap`; pindaian ber-`selesai` tidak pernah dipicu ulang; `satelit.yml` punya `concurrency` per pindaian dengan `cancel-in-progress: false` (dibaca dari YAML); run kedua untuk pindaian ber-`selesai` keluar tanpa menulis |
| T7 | Detektor api | `python3 -I scripts/data/api_himawari.py uji` | kasus sintetis: api di latar seragam terdeteksi, latar < 25 persen sah = `latar_kurang`, awan tidak jadi api, sumber statis dan kawah dibuang, kilau matahari dibuang, `penanda` diimpor |
| T7b | Kemandirian label api | `python3 -I scripts/data/api_himawari.py prasyarat` | jalur vonis gagal bila memanggil `penanda()` atau saringan VIIRS 72 jam; angka utama tanpa `himawari_alarm_palsu.csv`; baris "memakai VIIRS" terpisah; teks batas klaim ada di rapor |
| T8 | Kriteria api terkunci | `python3 -I scripts/data/api_himawari.py prasyarat` | gagal bila sidik berubah atau jangkar kosong; minggu uji tidak terbaca saat kalibrasi |
| T9 | Vonis api | `python3 scripts/data/api_himawari.py vonis` | entri `api_himawari` di `public/data/gerbang/satelit.json` lewat `gerbang.py`; dua pembanding pada jumlah alarm sama; median menit dahulu tercatat; n < 20 = tak dapat dinilai |
| T10 | Migrasi dan alarm | `npm run uji:warga` (`tests/warga/alarm_himawari*.test.mjs`) | baris lama `sumber = 'wlf'`; sumber `l1b` ditolak bila gerbang tidak `boleh_tampil` atau vonis prospektif bukan `lolos`; idempoten |
| T11 | Abu | `python3 -I scripts/gunungapi/abu_satelit.py uji`, `prasyarat`, lalu `vonis` | koreksi uap air menurunkan alarm pada kasus lembap sintetis; `koreksi_kurang` di bawah 200 piksel; gunung level I tidak dinilai; `prasyarat` menolak unduhan riwayat bila kriteria belum disidik dan dijangkar commit; vonis lawan VONA tertulis. **Harapan tertulis:** dengan arsip hidup saja n VONA < 20 dan vonis = "tak dapat dinilai"; vonis nyata hanya dari periode riwayat, dan bila riwayat pun n < 20, "tak dapat dinilai" diterima apa adanya |
| T12 | Konveksi | `python3 -I scripts/udara/awan_tumbuh.py uji` lalu `vonis` | definisi 30 menit lama sama dengan fixture sebelum perubahan (golden); OT sintetis terdeteksi, sirus dingin lebar tanpa cincin hangat tidak; paralaks tergeser ke arah benar; tiga pindaian bersinyal di satu kab satu hari = satu alarm kab-hari; pembanding mengambil tepat n_alarm (atau kurang dan tercatat); vonis lawan Dalops `cuaca` dengan `skor_dua` |
| T13 | Kawah dan SO2 | `python3 -I scripts/gunungapi/kawah.py uji`, `python3 -I scripts/gunungapi/so2.py uji` | api lereng di luar 2 km dibuang; median 0 = "baru muncul"; massa SO2 kasus 1 DU x 100 km2 = 2,85 t; lintasan berawan = `tak_teramati`; token tidak pernah tercetak |
| T14 | Genangan harian | `python3 -I scripts/banjir/genangan_harian.py uji` | hari tanpa lintasan tidak menghasilkan baris angka; status tak sah tidak pernah 0; memakai `hitung_pasangan` (bukan salinan) |
| T15 | VHI | `python3 -I scripts/kekeringan/vhi.py uji` | rerata per kab sintetis tepat; minggu tanpa data = tak teramati; vonis lawan Dalops kekeringan dan SPI-3 |
| T16 | Asap | `python3 -I scripts/udara/asap_aod.py uji` | kuantil 0,9 AI per kab tepat dari piksel (bukan dari seri provinsi); < 10 piksel = tak teramati; seri provinsi `tropomi.py` tidak berubah (golden); Spearman dan AUC lawan PM2.5 tercatat |
| T17 | Gerbang repo | `npm run uji:agen` | paket lengkap, berkas baru punya tepat satu pemilik, token warna tidak bertambah, kartu standar |
| T18 | INP dan selera | `inp-reviewer`, `selera-angka` | ganti jenis dan klik baris tidak membekukan; angka tanpa presisi palsu |
| T19 | Tinjau lokal | `http://localhost:8800/`, `/gunungapi`, `/cuaca`, `/banjir`, `/kekeringan`, `/udara`, `/instansi` | pemilik melihat kartu Satelit dan keadaan terputus |
| T20 | Ujung ke ujung seminggu | `satelit.yml` jalan dari pemicu Worker 7 hari; `python3 scripts/umum/himawari_pindai.py ukur --minggu` | per komponen tercatat (S3 LastModified lawan jam pindai, tik sampai dispatch, dispatch sampai `run_started_at`, unduh, hitung, unggah sampai etag Worker); median total <= 25 menit, p90 <= 35 menit; pindaian hilang dan `gagal_tetap` dihitung; tidak ada pindaian `selesai` dua kali |
| T21 | Gerbang anggaran | `python3 -I scripts/umum/himawari_pindai.py anggaran` | dari ukuran 1 hari riwayat: proyeksi GB per bulan <= Q5, kelas A <= 100 ribu, kelas B <= 1 juta per bulan; rerata potongan <= 50 KB, tidak ada > 200 KB; gagal = arsip tidak dinyalakan |

Periode uji: riwayat L1b dari bucket `noaa-himawari9` (mode `riwayat`, diunduh hanya sesudah kriteria tiap detektor dikunci): api musim kering 2026 (Jul sampai Okt), abu semua VONA ber-jam sejak Himawari-9 operasional, konveksi Nov 2025 sampai Mar 2026. Arsip WLF `arsip/himawari/` sebagai pembanding kedua api. Arsip hidup R2 untuk uji prospektif. Minggu atau gunung-tahun kalibrasi dan uji berselang, dipilih di kriteria sebelum dibaca.
