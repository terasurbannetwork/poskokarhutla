# Lampiran E. Glosarium

Glosarium ini memuat 72 istilah yang dipakai di naskah, disusun menurut abjad. Istilah asing yang sudah lazim dipakai (*hotspot*, *deduplication key*) tetap ditulis dalam bahasa aslinya dan dijelaskan di sini sekali.

Tabel E.1. Istilah dan artinya

| Istilah | Arti |
| --- | --- |
| Alasan masuk hitungan | Kolom berisi syarat yang membuat kejadian masuk hitungan bencana |
| Angka batas | Angka minimum dalam sebuah syarat atau kriteria, misalnya 50 orang terdampak; dalam kepustakaan disebut *threshold* atau ambang |
| Angka kumulatif | Angka yang sudah memuat angka hari sebelumnya, sehingga tidak boleh dijumlah antarhari |
| Angka statis | Angka yang dibekukan pada satu rilis bulanan bernomor versi dan tidak berubah sesudahnya; koreksi terbit sebagai rilis baru |
| Baris DIBI | Satu kombinasi hari, kabupaten/kota, dan jenis bencana di DIBI; belum tentu satu kejadian |
| *Baseline* | Angka dasar sebagai pembanding, misalnya jumlah kejadian sebelum aturan baru dipakai |
| [ANGKA SEMENTARA] | Penanda untuk angka atau pilihan yang dipakai sampai disesuaikan dengan data respons dan diputuskan pemilik data |
| [BELUM TERVERIFIKASI] | Penanda untuk fakta, pasal, atau angka yang belum dapat diperiksa dari sumber aslinya |
| BMKG | Badan Meteorologi, Klimatologi, dan Geofisika; penyedia katalog gempa |
| BNPB | Badan Nasional Penanggulangan Bencana |
| BPBD | Badan Penanggulangan Bencana Daerah |
| BPS | Badan Pusat Statistik; sumber data penduduk |
| Catatan kabupaten | Bagian kejadian di satu kabupaten atau kota, berkode KIB dan merujuk nomor induk kejadian nasional |
| *Cut-off* | Batas waktu pengambilan data; data yang masuk sesudahnya tidak ikut dihitung |
| *Deduplication key* | Cara mencocokkan baris harian logbook supaya laporan yang sama tidak terhitung dua kali, biasanya gabungan jenis, wilayah, dan tanggal |
| DesInventar | Sistem inventaris kerugian bencana yang dikelola bersama UNDRR; menyimpan data pada unit geografis terendah |
| DIBI | Data dan Informasi Bencana Indonesia; *database* kejadian bencana BNPB |
| *Double counting* | Penghitungan ganda: satu orang atau satu kejadian terhitung lebih dari sekali |
| Dana siap pakai | Dana yang disiapkan pemerintah untuk keadaan darurat; dicatat sebagai penanda dan tidak memasukkan kejadian ke hitungan |
| EM-DAT | Emergency Events Database; *database* bencana dunia milik CRED, Universitas Louvain, dengan syarat masuk 10 meninggal atau 100 terdampak |
| Evakuasi pencegahan | Pemindahan warga sebelum dampak terjadi; dicatat sebagai penanda dan tidak dihitung sebagai pengungsi |
| FIRMS | Fire Information for Resource Management System; sistem NASA yang membagikan data *hotspot* satelit |
| GAR | Global Assessment Report; laporan risiko bencana global UNDRR |
| GDACS | Global Disaster Alert and Coordination System; sistem peringatan bencana PBB dan Uni Eropa dengan tiga level warna |
| GLIDE | Nomor pengenal bencana global yang memuat kode negara |
| *Hotspot* | Titik panas yang dideteksi satelit; jumlahnya bergantung pada definisi, satelit, dan tingkat keyakinan yang dipakai, dan bukan sama dengan luas terbakar |
| Induk dan turunan (kejadian) | Bahaya pemicu menjadi kejadian induk; bahaya ikutan (misalnya tsunami, likuefaksi, longsor akibat banjir) menjadi kejadian turunan dengan jenisnya sendiri |
| Jeda (kejadian) | Lama tanpa laporan aktif yang memisahkan satu kejadian dari kejadian berikutnya; karhutla dan banjir 7 hari, gempa 30 hari |
| Juklak | Petunjuk pelaksanaan; Juklak BNPB 7/2023 memuat standar data kejadian dan dampak bencana |
| Kejadian di bawah ambang | Kejadian yang belum memenuhi satu pun syarat masuk hitungan; disimpan tetapi tidak dihitung sebagai bencana |
| Kejadian lintas tahun | Kejadian yang berawal di satu tahun dan berlanjut ke tahun berikutnya; dihitung pada tahun tanggal mulai |
| Kejadian majemuk | Kejadian dengan beberapa bahaya tanpa rantai sebab yang jelas; jenis utamanya adalah bahaya dengan dampak terbesar |
| Kejadian nasional | Satu kejadian utuh berapa pun jumlah wilayahnya, bernomor induk dari Pusdatinkom |
| Kelas keparahan | Empat kelas kejadian menurut dampaknya: Ringan, Sedang, Besar, dan Katastrofik |
| Kenaikan kelas untuk daerah berpenduduk kecil | Kelas naik satu tingkat, paling tinggi Besar, bila pengungsi ditambah terdampak langsung di satu kabupaten mencapai 10 persen penduduknya |
| Kerugian | Pendapatan dan biaya yang hilang akibat bencana, dicatat terpisah dari kerusakan |
| Kerusakan | Aset fisik yang rusak akibat bencana, dicatat terpisah dari kerugian |
| Kode Identitas Bencana (KIB) | Kode 16 digit identitas catatan bencana menurut Juklak 7/2023; memuat 2 angka provinsi dan 2 angka kabupaten |
| Kosong lawan nol | Isian kosong berarti belum didata, nol berarti terkonfirmasi nihil; keduanya tidak disamakan |
| Logbook | Catatan harian kejadian Pusdalops; satu barisnya (baris harian) memuat laporan satu kejadian pada satu hari |
| *Long tail* | Ekor panjang: sebagian kecil kejadian memikul sebagian besar korban atau kerusakan |
| Meninggal | Tewas akibat langsung bahaya dalam masa kejadian; kematian tidak langsung dicatat terpisah |
| Mengungsi | Meninggalkan rumah karena dampak; evakuasi pencegahan tidak termasuk |
| MMI | Modified Mercalli Intensity; skala intensitas guncangan di suatu tempat |
| Nihil | Terkonfirmasi nol menurut pernyataan BPBD |
| Nomor induk kejadian | Nomor yang dibawa tiap laporan, sehingga laporan susulan tidak perlu ditebak dari jenis, wilayah, dan tanggal |
| Nomor versi | Penanda rilis angka, dipakai bersama tanggal di setiap angka laporan pimpinan |
| PAGER | Prompt Assessment of Global Earthquakes for Response; sistem USGS yang memperkirakan korban dan kerugian gempa |
| Penanda | Catatan yang menyertai kejadian tetapi tidak memasukkannya ke hitungan, seperti permintaan bantuan nasional, status siaga, atau dana siap pakai |
| Perban dan Perka | Peraturan Badan BNPB dan Peraturan Kepala BNPB |
| Piksel | Satu sel citra satelit; piksel VIIRS mewakili sekitar 375 meter |
| *Proxy* luas | Luas terbakar yang diperkirakan dari jumlah piksel *hotspot*, bukan hasil ukur lapangan; tidak cukup untuk memenuhi syarat lahan |
| Pusdalops | Pusat Pengendalian Operasi BNPB; penyusun logbook dan laporan harian BNPB |
| Pusdatinkom | Pusat Data, Informasi, dan Komunikasi Kebencanaan BNPB; pengelola data bencana resmi (walidata) |
| Puso | Gagal panen |
| Rilis statis | Pembekuan angka per bulan dengan nomor versi |
| Risiko ekstensif | Kerugian yang sering terjadi dan berskala kecil, di bawah 30 meninggal dan di bawah 600 rumah hancur |
| Risiko intensif | Kerugian besar yang menewaskan 30 orang atau lebih atau menghancurkan 600 rumah atau lebih |
| Rumah rusak berat atau setaranya | Rumah rusak berat dihitung 1, rusak sedang 0,5, rusak ringan 0,25 |
| SK | Surat keputusan |
| Status darurat | Penetapan siaga darurat atau tanggap darurat oleh pejabat berwenang; hanya SK tanggap darurat yang cocok dengan kejadian yang menjadi syarat masuk |
| Tanggap darurat | Tahap penanganan segera sesudah bencana; angka tertentu memakai nilai terbesar selama tahap ini |
| Terdampak langsung | Penghuni rumah yang rusak atau tergenang, atau orang yang mata pencaharian atau akses air bersihnya terputus paling sedikit 3 hari |
| Tiga keadaan isian | Bernilai, nihil, atau belum didata |
| Tren | Arah naik atau turunnya angka dari waktu ke waktu |
| UNDRR | Kantor PBB untuk Pengurangan Risiko Bencana |
| USGS | United States Geological Survey; dinas geologi Amerika Serikat dan penyelenggara PAGER |
| UU 24/2007 | Undang-Undang Penanggulangan Bencana; Pasal 1 angka 1 mendefinisikan bencana |
| VEI | Volcanic Explosivity Index; skala eksplosivitas letusan gunung api dari 0 sampai 8 |
| VIIRS | Visible Infrared Imaging Radiometer Suite; sensor satelit pendeteksi *hotspot* beresolusi 375 meter |
| Walidata | Pihak yang memeriksa dan menetapkan data resmi; untuk bencana adalah Pusdatinkom |
| WIB dan UTC | Waktu Indonesia Barat dan waktu universal terkoordinasi; WIB sama dengan UTC ditambah 7 jam |
Sumber: Juklak 7/2023, Perban 1/2023, UU 24/2007, Perka BNPB 8/2011 dan 15/2011, laporan A/71/644 (Kerangka Sendai), dokumentasi EM-DAT dan UNDRR, serta daftar pustaka kajian ini.
