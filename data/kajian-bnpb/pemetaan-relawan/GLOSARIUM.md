# GLOSARIUM: Pemetaan bangunan oleh relawan

| Istilah | Arti |
| --- | --- |
| OSM | OpenStreetMap, peta terbuka yang disunting sukarelawan; lisensi ODbL. |
| HOT | Humanitarian OpenStreetMap Team, organisasi yang menjalankan Tasking Manager dan aktivasi kemanusiaan. |
| Tasking Manager | Alat HOT untuk memecah area jadi tugas persegi yang dipetakan dan divalidasi bergiliran. |
| Mapathon | Acara pemetaan bersama; antisipatif bila dilakukan sebelum bencana. |
| AOI | Area of interest, poligon area proyek yang diunggah ke Tasking Manager. |
| Open Buildings | Google Open Buildings v3, bangunan hasil deteksi citra (CC BY 4.0), pembanding di sini. |
| Overture | Overture Maps, gabungan OSM, Microsoft, Google; tidak dipakai sebagai pembanding karena memuat OSM. |
| Rasio kelengkapan | Bangunan OSM dibagi bangunan pembanding di zona bahaya; bukan kelengkapan mutlak. |
| Tipis, sedang, memadai | Kelas rasio (hipotesis Q6). |
| Hashtag changeset | Penanda di catatan suntingan OSM, bentuk `#CentuRisk-<kode>`, dasar hitungan sumbangan kampus. |
| ohsome | API publik OSM History Analytics dari HeiGIT; menghitung elemen OSM menurut waktu. |
| Penyuntingan terorganisir | Istilah pedoman OSM untuk suntingan kelompok atau lembaga; butuh halaman wiki dan komunikasi komunitas. |
| MapSwipe | Aplikasi seluler penyaring citra untuk menemukan area berbangunan; di luar lingkup F8. |
| Paket proyek | Berkas siap kirim yang disiapkan sistem; pengirimnya manusia. |
