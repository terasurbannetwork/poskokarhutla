# GLOSARIUM: Log tindak lanjut Usulan langkah

| Istilah | Arti |
| --- | --- |
| Usulan langkah | Daftar langkah BPBD bersama BNPB per kab/kota yang dihitung `H.mitigasi()` dari laporan terdampak, prakiraan status, dan posko. |
| Langkah | Satu baris tindakan di Usulan langkah, misalnya Posko, Evakuasi, Pantau lereng, Konfirmasi. |
| Kunci langkah | Pengenal stabil satu langkah: jenis bencana, kode provinsi, nama kab/kota, jenis langkah (ALGORITMA 1). |
| Status | Belum (tanpa catatan), Dikerjakan (`proses`), Selesai (`selesai`). |
| Log tindak lanjut | Riwayat append-only tiap perubahan status: waktu, pengisi, status, catatan, teks langkah saat itu (`dl_tindak_log`). |
| Pengisi | Staf Pusdalops/Koordalops atau moderator yang menyimpan status. |
| Pita kelompok | Baris berwarna di atas tiap kelompok (Terdampak belum surut, Awas, Siaga, Pantauan khusus). |
