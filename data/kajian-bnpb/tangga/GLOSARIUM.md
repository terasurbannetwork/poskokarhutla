# GLOSARIUM: Tangga Peringatan

| Istilah | Arti di modul ini |
| --- | --- |
| Tangga | Daftar pernyataan per skala waktu untuk satu kabupaten/kota, dari musim sampai jam. |
| Anak tangga | Satu skala waktu pada tangga. |
| Skala | musim, bulan, dasarian, 10 hari, sepekan, 3 hari, jam. |
| Kering | Kekeringan, karhutla, asap. |
| Basah | Banjir, longsor (dan hujan lebat sebagai pemicunya). |
| Pernyataan | Satu kalimat sumber dengan lembaga, tanggal, cakupan, dan label tingkat resmi. |
| Tingkat (`t`) | Label resmi persis seperti sumber (Waspada, Siaga, Awas, Atas Normal, dan seterusnya). |
| Peringkat (`tk`) | Angka 0 sampai 3 hanya untuk sinyal; pemetaannya di ALGORITMA 3. |
| Cakupan | nasional, provinsi, kabupaten, kecamatan: luas wilayah yang disebut sumber. |
| Searah | Skala yang lebih dekat menyatakan peringkat sama atau lebih tinggi, paling sedikit dua skala >= 1. |
| Menguat | Searah, naik tegas, dan semua skala bercakupan sama. |
| Belum selaras | Dua skala berselisih dua peringkat atau lebih. |
| ZOM | Zona Musim BMKG. |
| Dasarian | Sepuluh harian kalender: I tanggal 1 sampai 10, II 11 sampai 20, III 21 sampai akhir bulan. |
| Sifat hujan | Perbandingan hujan dengan rata-rata 30 tahun: Bawah Normal, Normal, Atas Normal, Jauh di Atas Normal. |
| Kita | Prediksi Centurisk97 dari `prediksi.json`; selalu dipisah dari BMKG. |
| Basi | Sumber lebih tua dari batas di ALGORITMA 6; tidak ditampilkan. |
