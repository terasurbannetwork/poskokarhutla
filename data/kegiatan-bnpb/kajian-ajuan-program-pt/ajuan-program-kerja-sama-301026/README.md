# Ajuan Program Kerja Sama BNPB dengan Perguruan Tinggi (30 Okt 2026, rev5)

Deck baseline dan kerangka awal program kerja sama BNPB dengan perguruan tinggi, disampaikan kepada Kepala BNPB.
Naskah, deck, dan dokumen turunan program PT (MoU, alur kerja sama, workshop region) diselaraskan ke deck ini.

| Berkas | Isi |
| --- | --- |
| `Ajuan Program Kerja Sama BNPB dengan Perguruan Tinggi 301026 rev5.pptx` | deck sumber, 14 slide |
| `Ajuan Program Kerja Sama BNPB dengan Perguruan Tinggi 301026 rev5.pdf` | versi edaran |
| `Ajuan Program Kerja Sama BNPB dengan Perguruan Tinggi 301026 rev5.manifest.json` | spek deck dari mesin ppt-konsultan |

Isi pokok:

1. Kebutuhan dan program: kebutuhan enam unit BNPB, rujukan internasional (IRIDeS, DPRI, FEMA, EERI, NHRA, QuakeCoRE), empat pilar dan 15 program (Fondasi, Pendidikan, Riset dan inovasi, Pengabdian dan relawan).
2. Regional dan mitra: 10 regional dan 1 tematik (karhutla dan gambut), 14 mitra pelaksana.
3. Peta jalan (100 hari pertama, 2027, 2028-2029) dan alternatif pendanaan per program.
4. Lampiran delapan inovasi perguruan tinggi.

Salinan asli ada di folder kerja pemilik `Kemitraan Perguruan Tinggi/03 Ajuan Program Kerja Sama 301026/` (revisi lama di subfolder `Revisi lama`).
